*Android 5.8.1: crash on launch on Android 9 (fix in PR #482)*

*Summary*
On Android 9, 5.8.1 crashes on launch because `WorkManager` is initialized twice. It runs once manually in `App.onCreate` and again through the default initializer in the manifest. PR #482 turns off the default initializer, so `App.onCreate` is the only place that initializes it.

---

*Manifest change* (`AndroidManifest.xml`, under the `InitializationProvider` entry)
`<meta-data android:name="androidx.work.WorkManagerInitializer" tools:node="remove" />`
`tools:node="remove"` removes the default `WorkManagerInitializer` from the merged manifest. No app code changes.

---

*Key files*
`AndroidManifest.xml`: turns off the default WorkManager initializer
`App.onCreate`: now the only place WorkManager is initialized (unchanged)
