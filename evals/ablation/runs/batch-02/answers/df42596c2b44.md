**🐞 Launch crash on Android 9: fix ready in PR #482**

**Summary**
Android app **5.8.1** crashes on launch for users on **Android 9**. `WorkManager` gets initialized twice: once manually in `App.onCreate`, and again through the default initializer declared in the merged manifest. The second initialization makes the app crash at startup.

**Fix (PR #482)**
In `AndroidManifest.xml`, under the `InitializationProvider` entry, the PR adds this line, which removes WorkManager's default initializer so only the manual init in `App.onCreate` runs:

```xml
<meta-data
    android:name="androidx.work.WorkManagerInitializer"
    tools:node="remove" />
```

**Files touched**
- `AndroidManifest.xml`: disables the default `WorkManagerInitializer`
- `App.kt` / `App.java` (`App.onCreate`): unchanged, now the single init point
