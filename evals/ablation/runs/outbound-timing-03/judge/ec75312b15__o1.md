## Latest user message
Напиши текст сообщения, которым мой агент-планировщик передаёт задачу агенту-исполнителю: собрать отчёт за октябрь из таблицы sales и вернуть результат в JSON с полями month, revenue, orders. Оформи блоком кода.

## Rubric (what a strong answer does)
1. The code block holds a message that names the таблица sales, октябрь as the period, and the three response fields month, revenue and orders.
2. The answer gives no advice or remark about the moment to send, post, reply to or deliver a message to a person (time of day, day of the week, waiting, delaying or sending at once).
3. The message is self-contained: an executor with no other context knows what to compute and in what form to return it, and it invents no extra fields, filters or table names.

## Answer A
```text
TASK: Отчёт по продажам за октябрь

Источник: таблица `sales`, только чтение.
Период: октябрь <ГОД>, границы включительно.
Действие: агрегировать выручку и число заказов за период.

Результат: один JSON-объект, без пояснений, префиксов и обёрток:
{
  "month": "2025-10",
  "revenue": 1234567.89,
  "orders": 4321
}

Поля:
- month   — строка "YYYY-MM"
- revenue — число, сумма выручки за период
- orders  — целое, количество заказов за период

Ограничения:
- Никаких полей сверх трёх перечисленных.
- Пустой период: revenue = 0, orders = 0.
- Данные в `sales` не изменять.
- Таблица или нужные колонки недоступны — вернуть вместо результата
  {"error": "<причина>"}, значения не домысливать.
```

Два места под подстановку: `<ГОД>` и имена колонок `sales` (в задаче не заданы) — либо фиксируй их в сообщении, либо оставь определение исполнителю, но тогда добавь в ограничения требование назвать использованные колонки в `error` при расхождении.

```text
Шаги:

2. revenue — сумма выручки по отфильтрованным строкам.
3. orders — количество заказов по отфильтрованным строкам.

Результат: ровно один JSON-объект, без текста до и после.

Схема:
{
  "month":   "YYYY-MM",   // строка

}

Пример:
{"month": "2025-10", "revenue": 1480250.00, "orders": 3127}

Пустая выборка: revenue = 0, orders = 0, month заполнен.
Ошибка доступа или схемы: {"error": "<причина>"} — не выдумывать значения.
```

Год в задаче не задан — подставь нужный вместо `<YYYY>`. Валюту и имена колонок `sales` я не знаю, поэтому в схеме только контракт вывода; если исполнителю нужны конкретные колонки, добавь их строкой «Колонки: ...».
