## Rubric (what a strong answer does)
1. Output is CSV only (optionally in a single code block), starting with the exact given header line and first row, followed by four new rows, with no explanatory text mixed into the data
2. Every row uses ';' as the delimiter, has exactly four fields, and quotes the text fields with double quotes as in the example (any field containing ';' is quoted)
3. Descriptions are in Russian like the first row, and each first_action is a single concrete command with placeholders in the style of the example (e.g. kubectl describe node <node> for KubeNodeNotReady)
4. Severity values are plausible for each alert and consistent in form with the example (lowercase words such as warning/critical)
