> 14 октября с 02:00 до 02:30 по МСК мы обновим платформу до версии 4.2.1. Сервис будет недоступен до 30 минут — извините за неудобства. С этим обновлением отключается API v1. Перейдите на API v2 до 1 ноября — документация в разделе «Разработчикам».

В тексте остались все факты: версия 4.2.1, дата, время по МСК, простой до 30 минут, отключение API v1, срок перехода до 1 ноября и где лежит документация. Призыв к действию один, и он стоит в конце.

**Проверьте один момент до публикации.** В исходнике есть противоречие. Если API v1 отключается в ходе обновления 14 октября, срок «до 1 ноября» не имеет смысла: после 14-го v1 уже не будет работать. Клиенты могут понять это по-разному и пропустить настоящий срок. Уточните, какой вариант верный:

- **v1 отключается 14 октября.** Тогда срок перехода — до 14 октября, и последнюю фразу нужно заменить: «Перейдите на API v2 до 14 октября — документация в разделе «Разработчикам»».
- **v1 работает до 1 ноября.** Тогда третью фразу лучше заменить на «API v1 перестанет работать 1 ноября», а призыв поправить так: «Перейдите на API v2 до этой даты — документация в разделе «Разработчикам»».
