## Why "it's clearly a PDF" doesn't carry the argument

- A PDF viewer toolbar shows that the page was *displayed* in a PDF viewer. It doesn't show the file came from the DMS export feature. Many DMS web viewers render documents in a PDF-style viewer, and print-to-PDF or a browser's "save as PDF" may not be logged as an "export." Whether your DMS's own in-browser viewer shows a toolbar like the one in the image is worth checking. If it does, that points toward a screenshot taken during a live viewing session, not an exported file.
- "Only one person exported" is the base-rate trap. The logged action is the most visible one, but it isn't the only way to capture a page.

5. **Compare the image with each rendering path.** Check toolbar style, page layout and how comments are drawn in the DMS web viewer versus an exported PDF opened in a desktop reader. That can tell you which path produced the image.
