- **"returns None if user not found"**: the code never returns `None` for a missing user. A 404 raises `UserNotFoundError`.
- **"timeout is in ms"**: the inline comment says `timeout` is passed through as a requests-style timeout in **seconds**. With the default `timeout=10`, that means 10 seconds, not 10 ms.

Here is the cleaned-up docstring. It's written against what the code actually does, and the code itself is unchanged:
