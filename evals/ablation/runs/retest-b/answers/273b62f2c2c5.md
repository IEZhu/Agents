## Запуск

1. Скопируйте файл с переменными окружения. Без этого шага сервис не запустится:

   ```bash
   cp .env.example .env
   ```

2. Запустите сервис:

   ```bash
   docker compose up -d
   ```

   После запуска сервис будет доступен по адресу http://localhost:8080.

3. Убедитесь, что сервис работает:

   ```bash
   curl http://localhost:8000/health
   ```

   Ожидаемый ответ: `{"status":"ok"}`.

### Смена порта

Если порт занят, задайте другой в переменной `APP_PORT` в файле `.env` (по умолчанию `8000`).

### Логи

```bash
docker compose logs -f app
```
```
