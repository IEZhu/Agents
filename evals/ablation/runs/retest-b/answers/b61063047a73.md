Before this goes out: the current docstring contradicts the code in two places. The rewrite below follows what the code actually does.

1. **"returns None if user not found"** is wrong. On a 404 the function raises `UserNotFoundError`. It never returns `None`.
2. **"timeout is in ms"** is wrong by a factor of 1000. The inline comment says the value is passed through as a requests-style timeout in **seconds**, so the default `10` means 10 seconds. A reader who trusts the old docstring and passes `timeout=5000` would wait over an hour.

The code itself is unchanged:

```python
def get_user(client, user_id, *, include_deleted=False, timeout=10):
    """Fetch a single user by ID.

    Args:
        client: The API client used to send the request.
        user_id: The ID of the user to fetch.
        include_deleted: If True, also search deleted users.
            Defaults to False.
        timeout: Request timeout in seconds. Defaults to 10.

    Returns:
        User: The requested user.

    Raises:
        UserNotFoundError: If no user with ``user_id`` exists
            (the API returns 404).
        HTTPError: If the API returns any other error status.
    """
    resp = client.request("GET", f"/users/{user_id}",
                          params={"deleted": include_deleted},
                          timeout=timeout)  # requests-style timeout, seconds
    if resp.status_code == 404:
        raise UserNotFoundError(user_id)
    resp.raise_for_status()
    return User.from_json(resp.json())
```

Some things to check before publishing:

- **`HTTPError`**: I assumed `resp.raise_for_status()` raises `requests.exceptions.HTTPError`, which is standard for `requests`. If `client` wraps a different library, such as `httpx`, which raises `httpx.HTTPStatusError`, update that line to match.
- **Docstring style**: I used Google style. If the rest of the SDK uses NumPy or reST (`:param:`) style, tell me and I'll convert it so the generated docs stay consistent.
- **Callers**: Code that checks `if get_user(...) is None` was written against the old docstring and will never hit that branch. It's worth searching for before the docs go live.
