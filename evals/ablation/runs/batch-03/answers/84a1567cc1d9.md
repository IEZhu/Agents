Структуру ниже я сделал целиком. Сначала одно возражение по сути, потом код.

## Что здесь полезно, а что преждевременно

Провайдер у вас один, и других в этом году не планируется. Поэтому часть запрошенной гибкости останется мёртвым кодом:

- **Полезно уже сейчас: ABC и DTO.** Бизнес-логика перестаёт зависеть от JSON ЮKassa, провайдера легко подменить фейком в тестах, а `Decimal` вместо `float` убирает реальный баг.
- **Преждевременно: реестр через декоратор, фабрика и выбор провайдера через env.** При одном провайдере значение переменной всегда одно и то же. Когда появится второй, это ~20 строк, которые пишутся за полчаса.
- **Главный риск: интерфейс, придуманный по одному провайдеру, почти наверняка окажется неправильным.** У Stripe, CloudPayments и Тинькофф разные модели вебхуков (подпись, HMAC, токен, у ЮKassa вообще без подписи), разные статусы, двухстадийные платежи, рекурренты и чеки по 54-ФЗ. Интерфейс лучше уточнить, когда рядом будет второй реальный провайдер.

Мой совет тимлиду: оставить ABC + DTO, а реестр и env-переключение не делать. Я всё же включил их в код, потому что вы просили именно так. Это отдельные небольшие файлы, их легко выкинуть.

## Баги в текущем коде (стоит починить при любой архитектуре)

1. **`float` для денег.** Нужен `Decimal`.
2. **`Idempotence-Key: order-{order_id}`.** Если пользователь не оплатил и платёж отменён, повторная попытка с тем же ключом вернёт тот же старый платёж. Насколько я помню, у ЮKassa ключ действует 24 часа (по памяти, не проверял, сверьтесь с документацией). Ключ нужен на каждую попытку оплаты, а не на заказ.
3. **Новый `AsyncClient` на каждый запрос.** Каждый раз заново открываются TCP- и TLS-соединения. Лучше один клиент на всё приложение, созданный в `lifespan`.
4. **`raise_for_status()` без контекста.** Ошибка теряет тело ответа ЮKassa, а из него видно, что именно не так.

```python
from dataclasses import dataclass
from decimal import Decimal
from enum import StrEnum


class PaymentStatus(StrEnum):
    PENDING = "pending"
    WAITING_FOR_CAPTURE = "waiting_for_capture"
    SUCCEEDED = "succeeded"
    CANCELED = "canceled"


class RefundStatus(StrEnum):
    PENDING = "pending"
    SUCCEEDED = "succeeded"
    CANCELED = "canceled"


@dataclass(frozen=True, slots=True)
class Money:
    amount: Decimal
    currency: str = "RUB"

    def __post_init__(self) -> None:
        if self.amount <= 0:
            raise ValueError(f"Money amount must be positive, got {self.amount}")


@dataclass(frozen=True, slots=True)
class CreatePaymentRequest:
    order_id: int
    amount: Money
    return_url: str
    idempotency_key: str  # уникален на ПОПЫТКУ оплаты, не на заказ
    description: str | None = None


@dataclass(frozen=True, slots=True)
class CreatePaymentResponse:
    payment_id: str
    status: PaymentStatus
    confirmation_url: str | None


@dataclass(frozen=True, slots=True)
class RefundRequest:
    payment_id: str
    amount: Money
    idempotency_key: str


@dataclass(frozen=True, slots=True)
class RefundResponse:
    refund_id: str
    status: RefundStatus


@dataclass(frozen=True, slots=True)
class PaymentInfo:
    payment_id: str
    status: PaymentStatus
    amount: Money
    order_id: int | None


@dataclass(frozen=True, slots=True)
class WebhookEvent:
    event_type: str        # в терминах провайдера, напр. "payment.succeeded"
    payment: PaymentInfo   # актуальное состояние, перечитанное из API
```

```python
class PaymentError(Exception):
    """Базовая ошибка платёжного слоя."""


class PaymentProviderError(PaymentError):
    def __init__(self, provider: str, message: str) -> None:
        super().__init__(f"[{provider}] {message}")
```

### `base.py`

```python
from abc import ABC, abstractmethod
from collections.abc import Mapping
from typing import ClassVar, Self

from .config import PaymentSettings
from .dto import (
    CreatePaymentRequest,
    CreatePaymentResponse,
    PaymentInfo,
    RefundRequest,
    RefundResponse,
    WebhookEvent,
)


class PaymentProvider(ABC):
    name: ClassVar[str]

    @classmethod
    @abstractmethod
    def from_settings(cls, settings: PaymentSettings) -> Self:
        """У каждого провайдера свои креды, поэтому конструирует себя сам."""

    @abstractmethod
    async def create_payment(self, request: CreatePaymentRequest) -> CreatePaymentResponse: ...

    @abstractmethod
    async def refund(self, request: RefundRequest) -> RefundResponse: ...

    @abstractmethod
    async def get_status(self, payment_id: str) -> PaymentInfo: ...

    @abstractmethod
    async def parse_webhook(
        self, body: bytes, headers: Mapping[str, str], client_ip: str | None
    ) -> WebhookEvent:
        """Проверить подлинность и нормализовать событие.

        Бизнес-логику (пометить заказ оплаченным) здесь НЕ делаем:
        это задача сервиса заказов, одинаковая для всех провайдеров.
        """

    async def aclose(self) -> None:  # noqa: B027 - необязательный хук
        return None
```

`handle_webhook` я намеренно переименовал в `parse_webhook`. Если провайдер сам «обрабатывает» вебхук, логика заказов расползётся по всем реализациям.

### `registry.py`

```python
from collections.abc import Callable
from typing import TypeVar

from .base import PaymentProvider
from .config import PaymentSettings
from .errors import UnknownProviderError

_P = TypeVar("_P", bound=type[PaymentProvider])
_REGISTRY: dict[str, type[PaymentProvider]] = {}


def register_provider(name: str) -> Callable[[_P], _P]:
    def decorator(cls: _P) -> _P:
        if name in _REGISTRY:
            raise ValueError(f"Payment provider {name!r} is already registered")
        cls.name = name
        _REGISTRY[name] = cls
        return cls

    return decorator


class ProviderFactory:
    @staticmethod
    def create(settings: PaymentSettings) -> PaymentProvider:
        try:
            provider_cls = _REGISTRY[settings.payment_provider]
        except KeyError:
            raise UnknownProviderError(
                f"Unknown payment provider {settings.payment_provider!r}; "
                f"registered: {sorted(_REGISTRY)}"
            ) from None
        return provider_cls.from_settings(settings)
```

У декоратора есть классическая ловушка: класс попадает в реестр, только если его модуль кто-то импортировал. Поэтому `providers/__init__.py` импортирует всех провайдеров явно:

```python

```

### `providers/yookassa.py`

```python
import ipaddress
import json
from collections.abc import Mapping
from decimal import Decimal
from typing import Any, Self

import httpx

from ..base import PaymentProvider
from ..config import PaymentSettings
from ..dto import (
    CreatePaymentRequest,
    CreatePaymentResponse,
    Money,
    PaymentInfo,
    PaymentStatus,
    RefundRequest,
    RefundResponse,
    RefundStatus,
    WebhookEvent,
)
from ..errors import PaymentProviderError, WebhookVerificationError
from ..registry import register_provider

YOOKASSA_API = "https://api.yookassa.ru/v3"

# Список IP для уведомлений ЮKassa по памяти, НЕ проверен.
# Сверьтесь с актуальной документацией перед продом.
_TRUSTED_NETWORKS = tuple(
    ipaddress.ip_network(n)
    for n in (
        "185.71.76.0/27",
        "185.71.77.0/27",
        "77.75.153.0/25",
        "77.75.156.11/32",
        "77.75.156.35/32",
        "77.75.154.128/25",
        "2a02:5180::/32",
    )
)


def _money_to_api(money: Money) -> dict[str, str]:
    return {"value": str(money.amount.quantize(Decimal("0.01"))), "currency": money.currency}


def _money_from_api(data: Mapping[str, Any]) -> Money:
    return Money(amount=Decimal(data["value"]), currency=data["currency"])


def _to_payment_info(data: Mapping[str, Any]) -> PaymentInfo:
    raw_order_id = data.get("metadata", {}).get("order_id")
    return PaymentInfo(
        payment_id=data["id"],
        status=PaymentStatus(data["status"]),
        amount=_money_from_api(data["amount"]),
        order_id=int(raw_order_id) if raw_order_id is not None else None,
    )


def _is_trusted_ip(client_ip: str | None) -> bool:
    if client_ip is None:
        return False
    try:
        addr = ipaddress.ip_address(client_ip)
    except ValueError:
        return False
    return any(addr in net for net in _TRUSTED_NETWORKS)


@register_provider("yookassa")
class YooKassaProvider(PaymentProvider):
    def __init__(self, client: httpx.AsyncClient) -> None:
        self._client = client

    @classmethod
    def from_settings(cls, settings: PaymentSettings) -> Self:
        if not settings.yookassa_shop_id or not settings.yookassa_secret_key.get_secret_value():
            raise ValueError("YOOKASSA_SHOP_ID and YOOKASSA_SECRET_KEY must be set")
        client = httpx.AsyncClient(
            base_url=YOOKASSA_API,
            auth=(settings.yookassa_shop_id, settings.yookassa_secret_key.get_secret_value()),
            timeout=settings.yookassa_timeout_s,
        )
        return cls(client)

    async def create_payment(self, request: CreatePaymentRequest) -> CreatePaymentResponse:
        payload: dict[str, Any] = {
            "amount": _money_to_api(request.amount),
            "confirmation": {"type": "redirect", "return_url": request.return_url},
            "capture": True,
            "metadata": {"order_id": str(request.order_id)},
        }
        if request.description:
            payload["description"] = request.description

        data = await self._request(
            "POST", "/payments", json=payload, idempotency_key=request.idempotency_key
        )
        return CreatePaymentResponse(
            payment_id=data["id"],
            status=PaymentStatus(data["status"]),
            confirmation_url=data.get("confirmation", {}).get("confirmation_url"),
        )

    async def refund(self, request: RefundRequest) -> RefundResponse:
        data = await self._request(
            "POST",
            "/refunds",
            json={"payment_id": request.payment_id, "amount": _money_to_api(request.amount)},
            idempotency_key=request.idempotency_key,
        )
        return RefundResponse(refund_id=data["id"], status=RefundStatus(data["status"]))

    async def get_status(self, payment_id: str) -> PaymentInfo:
        return _to_payment_info(await self._request("GET", f"/payments/{payment_id}"))

    async def parse_webhook(
        self, body: bytes, headers: Mapping[str, str], client_ip: str | None
    ) -> WebhookEvent:
        # ЮKassa, насколько я знаю, не подписывает уведомления. Защита такая:
        # allowlist IP + перечитать объект из API, а телу вебхука не доверять.
        if not _is_trusted_ip(client_ip):
            raise WebhookVerificationError(f"Untrusted webhook source IP: {client_ip}")
        try:
            event = json.loads(body)
            event_type: str = event["event"]
            obj = event["object"]
            payment_id: str = obj["payment_id"] if event_type.startswith("refund.") else obj["id"]
        except (ValueError, KeyError, TypeError) as exc:
            raise WebhookVerificationError("Malformed YooKassa webhook payload") from exc

        return WebhookEvent(event_type=event_type, payment=await self.get_status(payment_id))

    async def aclose(self) -> None:
        await self._client.aclose()

    async def _request(
        self,
        method: str,
        path: str,
        *,
        json: dict[str, Any] | None = None,
        idempotency_key: str | None = None,
    ) -> dict[str, Any]:
        headers = {"Idempotence-Key": idempotency_key} if idempotency_key else None
        try:
            resp = await self._client.request(method, path, json=json, headers=headers)
            resp.raise_for_status()
        except httpx.HTTPStatusError as exc:
            raise PaymentProviderError(
                self.name,
                f"{method} {path} -> {exc.response.status_code}: {exc.response.text[:500]}",
            ) from exc
        except httpx.HTTPError as exc:
            raise PaymentProviderError(self.name, f"{method} {path} failed: {exc!r}") from exc
        return resp.json()
```

### `dependencies.py`

```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

from fastapi import FastAPI, Request

from . import providers  # noqa: F401  (регистрация провайдеров)
from .base import PaymentProvider
from .config import PaymentSettings
from .registry import ProviderFactory


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    provider = ProviderFactory.create(PaymentSettings())  # fail fast при старте
    app.state.payment_provider = provider
    try:
        yield
    finally:
        await provider.aclose()


def get_payment_provider(request: Request) -> PaymentProvider:
    return request.app.state.payment_provider
```

### `webhooks.py`

```python
import logging

from fastapi import APIRouter, Depends, HTTPException, Request, Response

from .base import PaymentProvider
from .dependencies import get_payment_provider
from .errors import PaymentProviderError, WebhookVerificationError

logger = logging.getLogger(__name__)
router = APIRouter()


@router.post("/webhooks/payments")
async def payment_webhook(
    request: Request, provider: PaymentProvider = Depends(get_payment_provider)
) -> Response:
    client_ip = request.client.host if request.client else None
    try:
        event = await provider.parse_webhook(await request.body(), request.headers, client_ip)
    except WebhookVerificationError as exc:
        logger.warning("Rejected payment webhook: %s", exc)
        raise HTTPException(status_code=400) from exc
    except PaymentProviderError:
        logger.exception("Failed to re-fetch payment status for webhook")
        raise HTTPException(status_code=502)  # не 2xx, значит провайдер повторит доставку

    await apply_payment_event(event)  # ваш сервис заказов; ДОЛЖЕН быть идемпотентным
    return Response(status_code=200)
```

Если сервис стоит за nginx или балансировщиком, `request.client.host` будет IP прокси. Нужен `--proxy-headers` / `--forwarded-allow-ips` у uvicorn, иначе IP-allowlist отклонит всё подряд или, что хуже, пропустит всё подряд.

## Что проверить

- **Код я не запускал.** Проверьте типизацию (`mypy`) и тесты у себя.
- **Детали ЮKassa написаны по памяти и в этом ответе не проверены:** диапазоны IP для уведомлений, срок жизни `Idempotence-Key`, поле `payment_id` в объекте refund-события, тип значений в `metadata`. Всё это сверьте с документацией ЮKassa.
