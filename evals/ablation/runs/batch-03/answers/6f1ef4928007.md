Yes, you can rewrite these in bulk, and it is a sensible way to get green by Friday. A plain `sed` won't do it, though. The attribute name isn't the only thing that changes: the **object** you patch changes too, from `pricing` to `pricing.discounts`. So you need a regex with capture groups, and a small Python script is safer than `sed`.

Before you run it, keep one thing in mind. These tests failed on a refactor you checked against 2,000 real orders, so they were testing *how* `OrderPricing` works rather than *what* it returns. Retargeting them ties them to the new internals, and the next refactor will break them the same way. For Friday that trade-off is fine. Just don't treat the green suite as proof of more than it shows.

### The rewrite script

```python
#!/usr/bin/env python3
"""One-off: retarget mocks after splitting OrderPricing into components."""
import re
import sys
from pathlib import Path

# old private method on OrderPricing -> (component attribute, new method name)
RETARGET = {
    "_apply_tier_discount": ("discounts", "apply_tier"),
    "_compute_vat": ("taxes", "compute_vat"),      # adjust to your real names
    "_lookup_zone": ("shipping", "lookup_zone"),   # adjust to your real names
}

# patch.object(pricing, "_apply_tier_discount"  ->  patch.object(pricing.discounts, "apply_tier"
PATCH_OBJECT = re.compile(
    r"""patch\.object\(\s*(?P<obj>\w+)\s*,\s*(?P<q>["'])(?P<attr>_\w+)(?P=q)"""
)
# pricing._compute_vat(...)  ->  pricing.taxes.compute_vat(...)
DIRECT_ACCESS = re.compile(r"\b(?P<obj>\w+)\.(?P<attr>_\w+)\b")


def _retarget_patch(match: re.Match) -> str:
    if match["attr"] not in RETARGET:
        return match[0]
    component, new_name = RETARGET[match["attr"]]
    return f'patch.object({match["obj"]}.{component}, "{new_name}"'


def _retarget_access(match: re.Match) -> str:
    if match["attr"] not in RETARGET:
        return match[0]
    component, new_name = RETARGET[match["attr"]]
    return f'{match["obj"]}.{component}.{new_name}'


def main(paths: list[str]) -> None:
    for raw_path in paths:
        path = Path(raw_path)
        original = path.read_text()
        rewritten = DIRECT_ACCESS.sub(_retarget_access, PATCH_OBJECT.sub(_retarget_patch, original))
        if rewritten != original:
            path.write_text(rewritten)
            print(f"rewrote {path}")


if __name__ == "__main__":
    main(sys.argv[1:])
```

### What the script won't fix

Expect some of the 46 to still fail after the rewrite, for these reasons:

1. **Changed signatures.** `m.assert_called_once_with(order, "VIP")` still fails if `apply_tier` now takes something different, like `(tier, subtotal)` or no `order`. A regex can't fix that.
2. **Components created inside `total()`.** `patch.object(pricing.discounts, ...)` patches the instance that exists when the test runs. If `OrderPricing` builds its components lazily or per call instead of in `__init__`, the real method runs and the mock is never called. In that case, patch the class (`patch.object(DiscountEngine, "apply_tier")`) or inject the components.
3. **Methods that were merged or split.** If an old private method became two new ones, or disappeared, the test needs rewriting, not retargeting.
