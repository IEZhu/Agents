**On-call checklist: API deploy (prod)**

- [ ] **1. Check deployment status:** `kubectl rollout status deployment/api -n prod`
- [ ] **2. Roll back if needed:** if 5xx errors more than doubled within 10 minutes after the release, roll back: `kubectl rollout undo deployment/api -n prod`
- [ ] **3. Report in #incidents:** what was rolled back and at what time.
- [ ] **4. Do not restart the database** unless the on-call DBA has approved it.
- [ ] **5. After things stabilize,** open a ticket for the incident review (post-mortem).
