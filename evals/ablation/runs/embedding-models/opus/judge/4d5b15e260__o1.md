## Latest user message
Нужна регулярка (Python, re) для проверки российского мобильного номера. Должны проходить варианты вроде +7 912 345-67-89, 8 (912) 345-67-89, 89123456789 и +79123456789: пробелы, скобки и дефисы необязательны. Номер после +7 или 8 должен начинаться с 9. Дай регулярку и несколько проверок.

## Rubric (what a strong answer does)
1. The pattern accepts all four examples from the request.
2. It requires +7 or 8, then 9, then nine more digits, and rejects a wrong digit count or a first digit other than 9.
3. It is anchored to the whole string (re.fullmatch or ^...\Z) and comes with a few test cases.
4. The reply is in Russian, with code, commands and identifiers left as written, and contains no English restatement of the request.

## Answer A
Регулярка:

```python
import re

RU_MOBILE_RE = re.compile(
    r"(?:\+7|8)[ -]?(?:\(9[0-9]{2}\)|9[0-9]{2})[ -]?[0-9]{3}[ -]?[0-9]{2}[ -]?[0-9]{2}"
)

def is_ru_mobile(phone: str) -> bool:
    return RU_MOBILE_RE.fullmatch(phone) is not None
```

Как она устроена:

- `(?:\+7|8)`: префикс `+7` или `8`. Голая `7` без плюса не проходит.
- `(?:\(9[0-9]{2}\)|9[0-9]{2})`: код оператора начинается с `9`. Скобки допускаются только парой, поэтому `8 (912 345-67-89` не пройдёт. В варианте `\(?9\d{2}\)?` это было бы разрешено.
- `[ -]?` между группами: один необязательный пробел или дефис.
- `[0-9]` вместо `\d`, потому что в Python для `str` `\d` совпадает с любыми Unicode-цифрами, например с арабско-индийскими `٩`. Можно оставить `\d` и передать флаг `re.ASCII`.
- `fullmatch` вместо `^...$`: `$` пропускает строку с завершающим `\n`, а `fullmatch` нет.

Проверки:

```python
valid = [
    "+7 912 345-67-89",
    "8 (912) 345-67-89",
    "89123456789",
    "+79123456789",
    "8(912)3456789",
    "+7-912-345-67-89",
    "8 912 345 67 89",
]

invalid = [
    "+7 812 345-67-89",    # код начинается не с 9
    "7 912 345-67-89",     # нет плюса перед 7
    "+8 912 345-67-89",    # неверный префикс
    "8 (912 345-67-89",    # непарная скобка
    "8 912) 345-67-89",    # непарная скобка
    "8912345678",          # 10 цифр
    "891234567890",        # 12 цифр
    "8  912 345 67 89",    # двойной пробел
    "89123456789\n",       # хвостовой перевод строки
    "+7 912 345-67-8a",    # буква
    "",
]

for p in valid:
    assert is_ru_mobile(p), f"should match: {p!r}"
for p in invalid:
    assert not is_ru_mobile(p), f"should not match: {p!r}"
print("all checks passed")
```

Учтите несколько моментов:

- Разделители могут стоять между любыми группами, поэтому пройдут и смешанные форматы вроде `8 912-345 67-89`. Обычно это нормально. Если нужен строгий единый формат, регулярка станет заметно длиннее.
- Пробел перед скобкой тоже необязателен: `+7(912)...` проходит.
- Если номер дальше нужно хранить или сравнивать, удобнее сначала нормализовать его: `re.sub(r"[ ()-]", "", phone)`, а потом проверять простым `(?:\+7|8)9[0-9]{9}`. Так проще, но тогда перестанет ловиться непарная скобка.

## Answer B
Регулярка:

```python
import re

MOBILE_RU = re.compile(
    r"(?:\+7|8)[ -]?(?:\(9\d{2}\)|9\d{2})[ -]?\d{3}[ -]?\d{2}[ -]?\d{2}",
    re.ASCII,
)

def is_ru_mobile(phone: str) -> bool:
    return MOBILE_RU.fullmatch(phone) is not None
```

Как она устроена:

- `(?:\+7|8)` задаёт префикс. Голая `7` без плюса не проходит.
- `[ -]?` разрешает один необязательный пробел или дефис между группами.
- `(?:\(9\d{2}\)|9\d{2})` описывает код оператора, который начинается с 9. Он либо целиком в скобках, либо без них, поэтому непарная скобка вроде `(912 345...` не пройдёт.
- `\d{3} \d{2} \d{2}` даёт оставшиеся 7 цифр с необязательными разделителями.
- `fullmatch` вместо `match`/`search` с `^...$`. У `$` есть ловушка: он пропускает завершающий `\n`, и `"+79123456789\n"` прошёл бы проверку.
- `re.ASCII` нужен, чтобы `\d` означало только `0-9`. Без этого флага в Python 3 `\d` принимает и другие Unicode-цифры, например `٩١٢`.

Проверки:

```python
invalid = [

    "8 (912 345-67-89",    # непарная скобка
    "8 912) 345-67-89",    # непарная скобка
    "8912345678",          # 10 цифр
    "891234567890",        # 12 цифр

]

for p in valid:
    assert is_ru_mobile(p), f"should match: {p!r}"
for p in invalid:
    assert not is_ru_mobile(p), f"should not match: {p!r}"
print("ok")
```
