### Analysis

Классическая ловушка Python: **mutable default argument**. Значение по умолчанию (`[]`) создаётся **один раз** при определении функции (в момент `def`), а не при каждом вызове. Все вызовы, где `bucket` не передан явно, делят **один и тот же** объект списка.

### Implementation

```python
# ❌ Плохо: один и тот же list живёт всю жизнь функции
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket

add_item(1)  # [1]
add_item(2)  # [1, 2]  ← тот же список, а не новый
```

Проверка «одна ли это ссылка»:

```python
def f(a, b=[]):
    return b

f(1) is f(2)  # True — один и тот же объект
```

**Правильный вариант** — `None` как маркер «не передано», новый список создаём внутри:

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

add_item(1)  # [1]
add_item(2)  # [2]
```

Если нужно, чтобы вызов с явным `bucket` всё равно не мутировал аргумент:

```python
def add_item(item, bucket=None):
    bucket = list(bucket) if bucket is not None else []
    bucket.append(item)
    return bucket
```

### Verification

| Сценарий | `bucket=[]` | `bucket=None` |
|---|---|---|
| `add_item(1)` | `[1]` | `[1]` |
| `add_item(2)` | `[1, 2]` ← баг | `[2]` |
| `add_item(3, bucket=[10])` | `[10, 3]` | `[10, 3]` |

Правило общее: в Python **никогда** не используйте мутируемые объекты (`[]`, `{}`, `set()`) как значения по умолчанию. Всегда `None` + инициализация внутри.

### Confidence

**HIGH** — поведение определено спецификацией языка (CPython evaluates default values at function definition time); проверено мысленно на каждом вызове выше.
