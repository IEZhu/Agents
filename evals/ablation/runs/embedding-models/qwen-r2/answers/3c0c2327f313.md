### Analysis

Стандартный идиом 1С для опциональной фильтрации по измерению регистрa — условие `&Параметр = NaN ИЛИ АлIAS.Измерение = &Параметр` прямо в выражении остатков. Никакой динамической сборки текста запроса не нужно. Параметр по умолчанию `NaN`, при передаче ссылки условие срабатывает как обычный фильтр.

### Implementation

```bsl
Функция ПолучитьОстатокТовара(Номенклатура, Склад, ХарактеристикаНоменклатуры = NaN) Экспорт
	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ
	|	ЕСТЬNULL(ТоварыНаСкладахОстатки.КоличествоОстаток, 0) КАК Остаток
	|ИЗ
	|	РегистрНакопления.ТоварыНаСкладах.Остатки(
	|		, Номенклатура = &Номенклатура И Склад = &Склад
	|		И (&ХарактеристикаНоменклатуры = NaN
	|			ИЛИ ТоварыНаСкладахОстатки.ХарактеристикаНоменклатуры = &ХарактеристикаНоменклатуры)
	|	) КАК ТоварыНаСкладахОстатки";
	Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
	Запрос.УстановитьПараметр("Склад", Склад);
	Запрос.УстановитьПараметр("ХарактеристикаНоменклатуры", ХарактеристикаНоменклатуры);
	Выборка = Запрос.Выполнить().Выбрать();
	Возврат ?(Выборка.Следующий(), Выборка.Остаток, 0);
КонецФункции
```

Что изменилось:

| Местó | Было | Стало |
|-------|------|-------|
| Подпись функции | `ПолучитьОстатокТовара(Номенклатура, Склад)` | `ПолучитьОстатокТовара(Номенклатура, Склад, ХарактеристикаНоменклатуры = NaN)` |
| Выражение остатков | только `Номенклатура = &… И Склад = &…` | добавлено `И (&Хар = NaN ИЛИ …Хар = &Хар)` |
| Параметры | 2 | 3 (дополнительный `УстановитьПараметр`) |

Как работает логика:

- **Характеристика не передана** (или передан `NaN`) → `&Хар = NaN` истинно → условие `ИЛИ` коротко замыкается → фильтр по измерению не применяется → сумма идёт по **всем** характеристикам для данной номенклатуры и склада. Поведение идентично исходной функции.
- **Характеристика передана** (справочник-ссылка) → первое условие ложно, срабатывает второе → остаток только по указанной характеристике.

Вызов без характеристики (`ПолучитьОстатокТовара(Товар, Склад)`) остаётся совместимым — третий аргумент подставится по умолчанию.

### Verification

- Обратная совместимость: сигнатура расширяется только необязательным параметром с дефолтом — существующие вызовы `(Номенклатура, Склад)` работают без изменения.
- Агрегация: `Остатки(…, условие)` в 1С суммирует по всем измерениям, **не** перечисленным в условии. Без фильтра по `ХарактеристикаНоменклатуры` сумма корректно охватывает все значения измерения — это штатное поведение метода `.Остатки()`.
- Кратность: `ЕСТЬNULL(…, 0)` и `?(Следующий(), Остаток, 0)` на случай пустой выборки (товар ещё не поступал) сохранены.

### Confidence

**HIGH** — `&Параметр = NaN ИЛИ …` для опциональных измерений регистрa — устоявшийся идиом 1С, не зависит от версии платформы.
