В регистре ТоварыНаСкладах есть измерение ХарактеристикаНоменклатуры. Нужно, чтобы функция учитывала характеристику, если её передали, а если не передали — возвращала остаток по номенклатуре и складу, как раньше. Перепиши функцию.

## Rubric (what a strong answer does)
1. Adds an optional characteristic parameter and filters by ХарактеристикаНоменклатуры only when it is passed.
2. When no characteristic is passed, still returns the total over all characteristics: the filter stays in the virtual-table parameters, or СУММА is used if ХарактеристикаНоменклатуры appears in the outer query; never only the first characteristic's row.
3. Keeps the existing Russian identifiers (ПолучитьОстатокТовара, ТоварыНаСкладах, Номенклатура, Склад) exactly and writes valid 1C syntax.
4. Explains the change in Russian.

## Answer A
### Analysis

В регистрах накопления 1С измерения, которые **не** указаны в фильтре секции `.Остатки()`, автоматически агрегируются (суммируются по всем своим значениям). Значит, чтобы вернуть остаток по конкретной характеристике — добавляем условие в фильтр, чтобы вернуть «как раньше» (по всем характеристикам) — не добавляем. Реализуем это конкатенацией текста запроса: стандартный идиоматичный подход в 1С для условных частей запроса.

### Implementation

```1c
Функция ПолучитьОстатокТовара(Номенклатура, Склад, ХарактеристикаНоменклатуры = Неопределено) Экспорт
    Запрос = Новый Запрос;

    ТекстЗапроса =
        "ВЫБРАТЬ
        |   ЕСТЬNULL(ТоварыНаСкладахОстатки.КоличествоОстаток, 0) КАК Остаток
        |ИЗ
        |   РегистрНакопления.ТоварыНаСкладах.Остатки(, Номенклатура = &Номенклатура И Склад = &Склад";

    Если ХарактеристикаНоменклатуры <> Неопределено Тогда
        ТекстЗапроса = ТекстЗапроса + " И ХарактеристикаНоменклатуры = &ХарактеристикаНоменклатуры";
    КонецЕсли;

    ТекстЗапроса = ТекстЗапроса + ") КАК ТоварыНаСкладахОстатки";

    Запрос.Текст = ТекстЗапроса;
    Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
    Запрос.УстановитьПараметр("Склад", Склад);

    Если ХарактеристикаНоменклатуры <> Неопределено Тогда
        Запрос.УстановитьПараметр("ХарактеристикаНоменклатуры", ХарактеристикаНоменклатуры);
    КонецЕсли;

    Выборка = Запрос.Выполнить().Выбрать();
    Возврат ?(Выборка.Следующий(), Выборка.Остаток, 0);
КонецФункции
```

### Как это работает

| Вызов | Что делает запрос |
|-------|-------------------|
| `ПолучитьОстатокТовара(Товар, Склад)` | Третий параметр = `Неопределено` → условие по характеристике **не** добавляется → 1С сам суммирует по всем характеристикам. Поведение как раньше. |
| `ПолучитьОстатокТовара(Товар, Склад, Хarakт)` | Условие добавляется → возвращается остаток именно по этой характеристике. |

### Что изменилось относительно исходника

1. **Новый параметр** `ХарактеристикаНоменклатуры` со значением по умолчанию `Неопределено` — обратно совместим: все существующие вызовы с двумя аргументами продолжают работать без изменений.
2. **Динамический текст запроса** — стандартный приём в 1С, когда часть фильтра зависит от условия. Параметр `&ХарактеристикаНоменклатуры` устанавливается в запрос только при необходимости (иначе платформа выдаст ошибку «параметр не найден»).
3. **Остальная логика** (`ЕСТЬNULL`, `?()`, структура секции) не тронута.

### Confidence

**HIGH** — используется штатный механизм агрегации нефильтруемых измерений в регистрах накопления 1С и стандартный паттерн условной конкатенации текста запроса; логика покрыта двумя ветвями (с параметром / без), обратная совместимость сохранена.


## Answer B
### Analysis

Стандартный идиом 1С для опциональной фильтрации по измерению регистрa — условие `&Параметр = NaN ИЛИ АлIAS.Измерение = &Параметр` прямо в выражении остатков. Никакой динамической сборки текста запроса не нужно. Параметр по умолчанию `NaN`, при передаче ссылки условие срабатывает как обычный фильтр.

### Implementation

```bsl
Функция ПолучитьОстатокТовара(Номенклатура, Склад, ХарактеристикаНоменклатуры = NaN) Экспорт
	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ
	|	ЕСТЬNULL(ТоварыНаСкладахОстатки.КоличествоОстаток, 0) КАК Остаток
	|ИЗ
	|	РегистрНакопления.ТоварыНаСкладах.Остатки(
	|		, Номенклатура = &Номенклатура И Склад = &Склад
	|		И (&ХарактеристикаНоменклатуры = NaN
	|			ИЛИ ТоварыНаСкладахОстатки.ХарактеристикаНоменклатуры = &ХарактеристикаНоменклатуры)
	|	) КАК ТоварыНаСкладахОстатки";
	Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
	Запрос.УстановитьПараметр("Склад", Склад);
	Запрос.УстановитьПараметр("ХарактеристикаНоменклатуры", ХарактеристикаНоменклатуры);
	Выборка = Запрос.Выполнить().Выбрать();
	Возврат ?(Выборка.Следующий(), Выборка.Остаток, 0);
КонецФункции
```

Что изменилось:

| Местó | Было | Стало |
|-------|------|-------|
| Подпись функции | `ПолучитьОстатокТовара(Номенклатура, Склад)` | `ПолучитьОстатокТовара(Номенклатура, Склад, ХарактеристикаНоменклатуры = NaN)` |
| Выражение остатков | только `Номенклатура = &… И Склад = &…` | добавлено `И (&Хар = NaN ИЛИ …Хар = &Хар)` |
| Параметры | 2 | 3 (дополнительный `УстановитьПараметр`) |

Как работает логика:

- **Характеристика не передана** (или передан `NaN`) → `&Хар = NaN` истинно → условие `ИЛИ` коротко замыкается → фильтр по измерению не применяется → сумма идёт по **всем** характеристикам для данной номенклатуры и склада. Поведение идентично исходной функции.
- **Характеристика передана** (справочник-ссылка) → первое условие ложно, срабатывает второе → остаток только по указанной характеристике.

Вызов без характеристики (`ПолучитьОстатокТовара(Товар, Склад)`) остаётся совместимым — третий аргумент подставится по умолчанию.

### Verification

- Обратная совместимость: сигнатура расширяется только необязательным параметром с дефолтом — существующие вызовы `(Номенклатура, Склад)` работают без изменения.
- Агрегация: `Остатки(…, условие)` в 1С суммирует по всем измерениям, **не** перечисленным в условии. Без фильтра по `ХарактеристикаНоменклатуры` сумма корректно охватывает все значения измерения — это штатное поведение метода `.Остатки()`.
- Кратность: `ЕСТЬNULL(…, 0)` и `?(Следующий(), Остаток, 0)` на случай пустой выборки (товар ещё не поступал) сохранены.

### Confidence

**HIGH** — `&Параметр = NaN ИЛИ …` для опциональных измерений регистрa — устоявшийся идиом 1С, не зависит от версии платформы.
