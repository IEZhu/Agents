## Latest user message
Нужна регулярка (Python, re) для проверки российского мобильного номера. Должны проходить варианты вроде +7 912 345-67-89, 8 (912) 345-67-89, 89123456789 и +79123456789: пробелы, скобки и дефисы необязательны. Номер после +7 или 8 должен начинаться с 9. Дай регулярку и несколько проверок.

## Rubric (what a strong answer does)
1. The pattern accepts all four examples from the request.
2. It requires +7 or 8, then 9, then nine more digits, and rejects a wrong digit count or a first digit other than 9.
3. It is anchored to the whole string (re.fullmatch or ^...\Z) and comes with a few test cases.
4. The reply is in Russian, with code, commands and identifiers left as written, and contains no English restatement of the request.

## Answer A
### Analysis

Структура российского мобильного: префикс `+7` или `8`, затем 10 цифр, первая из которых `9`. Между цифрами допустимы пробелы, дефисы, скобки — в любом сочетании. Регулярка: жёстко фиксирует префикс и первую цифру, а между остальными цифрами разрешает «клей» из разделителей.

### Implementation

```python
import re

RU_MOBILE_RE = re.compile(r'^(\+7|8)[\s\-()]*9(?:[\s\-()]*\d){9}$')


def is_russian_mobile(number: str) -> bool:
    return bool(RU_MOBILE_RE.match(number))
```

Логика по частям:

| Фрагмент | Что делает |
|----------|-----------|
| `^(\+7\|8)` | Префикс: `+7` или `8` (без `+`) |
| `[\s\-()]*` | Ноль или более разделителей перед первой цифрой |
| `9` | Первая цифра абонентского номера — обязательная `9` |
| `(?:[\s\-()]*\d){9}` | Ещё 9 цифр, перед каждой — опциональный «клей» |
| `$` | Конец строки, лишних символов нет |

### Verification

```python
import pytest

# --- Должны пройти ---
@pytest.mark.parametrize("num", [
    "+7 912 345-67-89",
    "8 (912) 345-67-89",
    "89123456789",
    "+79123456789",
    "8-912-345-67-89",
    "+7 9123456789",
    "89123456789",
])
def test_valid(num):
    assert is_russian_mobile(num), f"Expected {num!r} to pass"

# --- Должны НЕ пройти ---
@pytest.mark.parametrize("num", [
    "9123456789",        # нет префикса
    "+7 812 345-67-89",  # первая цифра не 9
    "+7 912 345-67-8",   # 9 цифр, не 10
    "+8 912 345-67-89",  # +8 — невалидный префикс
    "7 912 345-67-89",   # 7 без + и без роли «8»
    "+7 912 345-67-89 ", # лишний пробел в конце
    "8 912 345-67-890",  # 11 цифр
])
def test_invalid(num):
    assert not is_russian_mobile(num), f"Expected {num!r} to fail"
```

## Answer B
Вот строгая regex для Python `re`. Она проверяет **всю строку**, требует префикс `+7` или `8`, затем ровно **10 цифр**, где первая обязательна `9`. Между цифрами могут быть пробелы, скобки и дефисы.

```python
import re

RU_MOBILE_RE = re.compile(r'^(?:\+7|8)[\s()\-]*9(?:[\s()\-]*[0-9]){9}$')


def is_ru_mobile(value: str) -> bool:
    return RU_MOBILE_RE.fullmatch(value) is not None
```

### Проверки

```python
checks = [
    # должны пройти
    ("+7 912 345-67-89", True),
    ("8 (912) 345-67-89", True),
    ("89123456789", True),
    ("+79123456789", True),

    # тоже должны пройти
    ("+7 912 345 67 89", True),
    ("8-912-345-67-89", True),
    ("8 9 12 345 67 89", True),

    # не должны пройти
    ("8 812 345 67 89", False),      # после 8 не 9
    ("+7 812 345 67 89", False),     # после +7 не 9
    ("79123456789", False),          # нет префикса +7 или 8
    ("+8 912 345 67 89", False),     # +8 не поддерживается
    ("8912345678", False),           # не хватает цифры
    ("891234567890", False),         # лишний символ/цифра
    ("8 912 345 67 89 ", False),     # пробел в конце
]

for value, expected in checks:
    actual = is_ru_mobile(value)
    print(f"{actual == expected}\t{value}")
```

```python

```

Если хочешь более строгий вариант, где скобки разрешены только как пара вокруг первых трёх цифр после префикса, например `8 (912) 345-67-89`, но не `8 (912 3456789`, используй:

```python
RU_MOBILE_STRICT_RE = re.compile(
    r'^(?:\+7|8)[\s\-]*(?:\((?:9[0-9][0-9])\)|9[0-9][0-9])(?:[\s\-]*[0-9]){7}$'
)
```
