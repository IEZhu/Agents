## Answer A
### Analysis
Вы столкнулись с одной из самых известных ловушек в Python — **изменяемыми аргументами по умолчанию (Mutable Default Arguments)**.

Проблема в том, что в Python значения аргументов по умолчанию вычисляются **один раз** в момент определения функции, а не при каждом её вызове. Поскольку список `[]` является изменяемым объектом, Python создает один и тот же экземпляр списка при инициализации функции и переиспользует его при каждом вызове, где аргумент `bucket` не передан.

### Implementation

Чтобы исправить это, следует использовать `None` в качестве значения по умолчанию. Это стандартный паттерн в Python для работы с изменяемыми типами данных.

```python
def add_item(item, bucket=None):
    # Если bucket не передан (равен None), создаем новый список прямо внутри функции
    if bucket is None:
        bucket = []
    
    bucket.append(item)
    return bucket

# Проверка
print(add_item(1))  # Результат: [1] (создан новый список)
print(add_item(2))  # Результат: [2] (создан еще один новый список)

# При этом функция по-прежнему позволяет передать существующий список:
my_list = [10, 20]
print(add_item(3, my_list))  # Результат: [10, 20, 3]
```

### Verification

1.  **Первый вызов `add_item(1)`**: `bucket` равен `None` $\rightarrow$ создается новый список `[]` $\rightarrow$ добавляется `1` $\rightarrow$ возвращается `[1]`.
2.  **Второй вызов `add_item(2)`**: `bucket` снова равен `None` $\rightarrow$ создается **новый** пустой список `[]` $\rightarrow$ добавляется `2` $\rightarrow$ возвращается `[2]`.
3.  **Сложность**: Временная сложность $\mathcal{O}(1)$ для добавления элемента, пространственная $\mathcal{O}(n)$ для хранения списка.

**Почему это работает:**
Теперь создание списка `bucket = []` происходит в теле функции (runtime), а не в её заголовке (definition time). Таким образом, при каждом вызове без аргумента создается свежий объект.

### Confidence
HIGH — Это классический пример поведения Python, решение является общепринятым стандартом (PEP 8 / Python idiomatic code).


## Answer B
### Analysis
Вы столкнулись с одной из самых известных особенностей Python, которая называется **«изменяемые значения по умолчанию» (Mutable Default Arguments)**. 

Проблема в том, что в Python значения аргументов по умолчанию вычисляются **один раз в момент определения функции**, а не при каждом её вызове. Когда вы написали `bucket=[]`, Python создал один единственный список в памяти и «привязал» его к функции. Все последующие вызовы функции, в которых вы не передали свой список, используют этот один и тот же объект.

### Implementation

#### Как это работает сейчас (неправильно):
```python
def add_item(item, bucket=[]): # Список создается ОДИН РАЗ при загрузке кода
    bucket.append(item)
    return bucket

# 1-й вызов: используется общий список, в него добавляется 1
print(add_item(1)) # [1]
# 2-й вызов: используется ТОТ ЖЕ самый список, в него добавляется 2
print(add_item(2)) # [1, 2]
```

#### Как написать правильно:
Стандартный паттерн в Python для решения этой проблемы — использовать `None` в качестве значения по умолчанию, а затем инициализировать список внутри тела функции.

```python
def add_item(item, bucket=None):
    # Если bucket не был передан, создаем НОВЫЙ список прямо сейчас
    if bucket is None:
        bucket = []
    
    bucket.append(item)
    return bucket

# Теперь всё работает ожидаемо:
print(add_item(1)) # [1] — создан новый список
print(add_item(2)) # [2] — создан еще один новый список

# При этом вы всё еще можете передать свой список, если это нужно:
my_list = [10, 20]
print(add_item(30, my_list)) # [10, 20, 30]
```

### Verification
1. **Первый вызов**: `bucket` равен `None` $\rightarrow$ создается новый список `[]` $\rightarrow$ результат `[1]`.
2. **Второй вызов**: `bucket` снова равен `None` (так как это новый вызов) $\rightarrow$ создается **другой** новый список `[]` $\rightarrow$ результат `[2]`.
3. **Передача своего списка**: `bucket` не равен `None` $\rightarrow$ условие `if` пропускается $\rightarrow$ модифицируется переданный объект.

**Сложность**:
- Временная сложность: $O(1)$ для добавления элемента.
- Пространственная сложность: $O(n)$ в зависимости от количества элементов в списке.

### Confidence
HIGH — это фундаментальная особенность реализации языка Python, и предложенный способ с `None` является общепринятым стандартом (PEP 8 и лучшие практики).
