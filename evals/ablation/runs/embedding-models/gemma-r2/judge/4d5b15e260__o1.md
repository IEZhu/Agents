Нужна регулярка (Python, re) для проверки российского мобильного номера. Должны проходить варианты вроде +7 912 345-67-89, 8 (912) 345-67-89, 89123456789 и +79123456789: пробелы, скобки и дефисы необязательны. Номер после +7 или 8 должен начинаться с 9. Дай регулярку и несколько проверок.

## Rubric (what a strong answer does)
1. The pattern accepts all four examples from the request.
2. It requires +7 or 8, then 9, then nine more digits, and rejects a wrong digit count or a first digit other than 9.
3. It is anchored to the whole string (re.fullmatch or ^...\Z) and comes with a few test cases.
4. The reply is in Russian, with code, commands and identifiers left as written, and contains no English restatement of the request.

## Answer A
### Analysis
Для решения этой задачи лучше всего использовать регулярное выражение, которое разделяет проверку на две части: префикс (`+7` или `8`) и основное тело номера (начинающееся с `9` и содержащее еще 9 цифр), разрешая при этом произвольное вкрапление служебных символов (пробелы, скобки, дефисы).

Оптимальный паттерн: `^(\+7|8)[\s\-()]*9([\s\-()]*\d){9}$`

### Implementation

```python
import re

def validate_russian_phone(phone):
    # Регулярное выражение:
    # ^(\+7|8)        - Начинается с +7 или 8
    # [\s\-()]*       - Любое количество пробелов, дефисов или скобок
    # 9               - Обязательная девятка после префикса
    # ([\s\-()]*\d){9} - 9 цифр, каждая из которых может быть preceded служебными символами
    # $               - Конец строки
    pattern = r'^(\+7|8)[\s\-()]*9([\s\-()]*\d){9}$'
    
    if re.match(pattern, phone):
        return True
    return False

# Тестовые случаи
test_cases = [
    # Валидные
    ("+7 912 345-67-89", True),
    ("8 (912) 345-67-89", True),
    ("89123456789", True),
    ("+79123456789", True),
    ("8-912-345-67-89", True),
    ("+7(912)3456789", True),
    
    # Невалидные
    ("+7 812 345-67-89", False), # Начинается с 8 вместо 9
    ("7 912 345-67-89", False),  # Нет + перед 7
    ("8 912 345-67", False),     # Слишком короткий
    ("8 912 345-67-89-0", False), # Слишком длинный
    ("912 345-67-89", False),    # Нет префикса 7 или 8
    ("abc 912 345-67-89", False),# Мусор в начале
]

print(f"{'Номер':<20} | {'Ожидание':<10} | {'Результат':<10}")
print("-" * 45)
for phone, expected in test_cases:
    result = validate_russian_phone(phone)
    status = "✅" if result == expected else "❌"
    print(f"{phone:<20} | {str(expected):<10} | {str(result):<10} {status}")
```

### Verification

1.  **Префиксы**: Проверены `+7` и `8`. Вариант просто `7` (без плюса) отклоняется, так как это не соответствует стандарту.
2.  **Первая цифра**: Условие "начинаться с 9" строго соблюдено (`...9([\s\-()]*\d){9}`).
3.  **Длина**: После префикса строго 10 цифр (9 + еще 9). Лишние или недостающие цифры приводят к `False`.
4.  **Символы**: `[\s\-()]*` позволяет вставлять пробелы, тире и скобки в любом месте между цифрами.
5.  **Сложность**: Временная сложность $\mathcal{O}(n)$, где $n$ — длина строки. Память $\mathcal{O}(1)$.

### Confidence
HIGH — Регулярное выражение покрывает все указанные требования и краевые случаи.


## Answer B
### Analysis
Для решения этой задачи потребуется регулярное выражение, которое гибко обрабатывает разделители, но строго контролирует количество цифр и начальные символы.

**Ключевые требования:**
1. Начало: либо `+7`, либо `8`.
2. Первая цифра после префикса: обязательно `9`.
3. Общее количество цифр: 11.
4. Разрешенные разделители: пробелы, дефисы, скобки (в любом месте или в их отсутствие).

Я предлагаю использовать паттерн, который проверяет префикс и первую цифру `9`, а затем ищет оставшиеся 9 цифр, позволяя между ними встречаться произвольным разделителям.

### Implementation

```python
import re

def validate_russian_phone(phone: str) -> bool:
    # Регулярное выражение:
    # ^(?:\+7|8)          - начало строки, группа без захвата: либо +7, либо 8
    # [\s\-()]*           - любое количество разделителей (пробел, дефис, скобки)
    # 9                   - обязательная девятка
    # (?:\s*[-()]*\d){9}  - группа из 9 повторений: опциональный разделитель и одна цифра
    # $                   - конец строки
    pattern = r'^(?:\+7|8)[\s\-()]*9(?:\s*[-()]*\d){9}$'
    
    return bool(re.match(pattern, phone))

# --- Тестирование ---
test_cases = {
    "+7 912 345-67-89": True,   # Стандарт с пробелами и дефисом
    "8 (912) 345-67-89": True,  # Стандарт со скобками
    "89123456789": True,        # Без разделителей (8...)
    "+79123456789": True,       # Без разделителей (+7...)
    "+7(912)3456789": True,     # Слитно со скобками
    "79123456789": False,       # Нет + или 8 в начале
    "+7 812 345-67-89": False,  # Начинается с 8 (не мобильный)
    "+7 912 345-67-8": False,   # Слишком короткий
    "+7 912 345-67-890": False, # Слишком длинный
    "8-912-345-67-89": True,    # Только дефисы
}

print(f"{'Phone Number':<20} | {'Expected':<10} | {'Result':<10}")
print("-" * 45)
for phone, expected in test_cases.items():
    result = validate_russian_phone(phone)
    status = "✅" if result == expected else "❌"
    print(f"{phone:<20} | {str(expected):<10} | {str(result):<10} {status}")
```

### Verification

**Разбор работы регулярки:**
- `^(?:\+7|8)`: Гарантирует, что строка начинается строго с `+7` или `8`.
- `[\s\-()]*9`: Ищет первую обязательную девятку, игнорируя возможные скобки или пробелы перед ней (например, в случае `8 (9...`).
- `(?:\s*[-()]*\d){9}$`: Это самая важная часть. Вместо того чтобы просто написать `\d{9}`, мы создаем группу, которая ищет «возможный разделитель + одна цифра» ровно 9 раз. Это позволяет номеру быть как `3456789`, так и `345-67-89`.

**Сложность:**
- Временная сложность: $O(N)$, где $N$ — длина строки.
- Пространственная сложность: $O(1)$.

**Профессиональный совет:** 
Если эта проверка используется в реальном проекте с большой нагрузкой, я рекомендую сначала очищать строку от всех не-цифр (кроме знака `+`), а затем проверять результат простой регуляркой `^(\+7|8)9\d{9}$`. Это делает код более читаемым и менее подверженным ошибкам при изменении форматов разделителей.

### Confidence
HIGH — Регулярное выражение покрывает все указанные кейсы и обрабатывает границы строки.
