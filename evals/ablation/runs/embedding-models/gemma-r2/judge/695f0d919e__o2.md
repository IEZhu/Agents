## Answer A
### Analysis
Задача требует модификации функции для поддержки необязательного фильтра по измерению `ХарактеристикаНоменклатуры`. 

**Ключевое архитектурное решение:** 
В 1С фильтрация виртуальных таблиц (в данном случае `.Остатки`) должна происходить именно в параметрах виртуальной таблицы, а не в секции `ГДЕ`. Это критически важно для производительности, так как позволяет СУБД ограничить выборку данных еще на этапе чтения из таблиц итогов. 

Поскольку условие фильтрации меняется динамически (характеристика может быть, а может и не быть), оптимальным решением будет формирование строки фильтра в коде перед передачей её в текст запроса.

### Implementation

```bsl
Функция ПолучитьОстатокТовара(Номенклатура, Склад, Характеристика = Неопределено) Экспорт
	
	Запрос = Новый Запрос;
	
	// Формируем строку фильтра для виртуальной таблицы.
	// Обязательные фильтры всегда присутствуют.
	ТекстФильтра = "Номенклатура = &Номенклатура И Склад = &Склад";
	
	// Если характеристика передана и заполнена, добавляем её в фильтр.
	Если ЗначениеЗаполнено(Характеристика) Тогда
		ТекстФильтра = ТекстФильтра + " И ХарактеристикаНоменклатуры = &Характеристика";
	КонецЕсли;
	
	Запрос.Текст = 
	"ВЫБРАТЬ
	|	ЕСТЬNULL(ТоварыНаСкладахОстатки.КоличествоОстаток, 0) КАК Остаток
	|ИЗ
	|	РегистрНакопления.ТоварыНаСкладах.Остатки(, " + ТекстФильтра + ") КАК ТоварыНаСкладахОстатки";
	
	Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
	Запрос.УстановитьПараметр("Склад", Склад);
	
	Если ЗначениеЗаполнено(Характеристика) Тогда
		Запрос.УстановитьПараметр("Характеристика", Характеристика);
	КонецЕсли;
	
	Выборка = Запрос.Выполнить().Выбрать();
	
	Возврат ?(Выборка.Следующий(), Выборка.Остаток, 0);
	
КонецФункции
```

### Verification

**Рассмотренные сценарии:**
1. **Переданы только Номенклатура и Склад:** 
   - `Характеристика` принимает значение по умолчанию `Неопределено`.
   - `ЗначениеЗаполнено(Характеристика)` возвращает `Ложь`.
   - Запрос выполняется с фильтром `Номенклатура = &Номенклатура И Склад = &Склад`. 
   - Результат: сумма остатков по всем характеристикам данной номенклатуры на указанном складе. (Поведение сохранено).
2. **Передана заполненная Характеристика:**
   - `ЗначениеЗаполнено(Характеристика)` возвращает `Истина`.
   - В строку фильтра добавляется условие по характеристике.
   - Устанавливается соответствующий параметр запроса.
   - Результат: остаток конкретной характеристики.
3. **Передана пустая ссылка в качестве характеристики:**
   - `ЗначениеЗаполнено()` корректно обработает пустую ссылку как `Ложь`, и функция отработает по общему остатку, что предотвращает ошибку поиска по "пустой" характеристике, если она не используется в учете.

**Сложность:**
- Временная сложность: $O(1)$ (выполнение одного точечного запроса к индексированным полям виртуальной таблицы).
- Пространственная сложность: $O(1)$.

### Confidence
HIGH — Решение соответствует стандартам разработки 1С (использование параметров виртуальных таблиц), обрабатывает краевые случаи с пустыми значениями и полностью сохраняет обратную совместимость.


## Answer B
### Analysis
Задача состоит в том, чтобы сделать фильтрацию по характеристике опциональной, сохранив при этом производительность запроса. 

Ключевой технический момент в 1С: фильтрацию по измерениям в виртуальных таблицах (таких как `.Остатки`) необходимо передавать именно в **параметрах виртуальной таблицы**, а не в секции `ГДЕ`. Если добавить условие в `ГДЕ`, платформа сначала выберет все остатки по всем характеристикам, а затем отфильтрует их, что приведет к падению производительности на больших объемах данных.

### Implementation

Для решения я добавлю третий параметр с значением по умолчанию `Неопределено` и буду динамически формировать строку фильтра для виртуальной таблицы.

```bsl
Функция ПолучитьОстатокТовара(Номенклатура, Склад, ХарактеристикаНоменклатура = Неопределено) Экспорт
	
	// 1. Формируем базовый фильтр
	ТекстФильтра = "Номенклатура = &Номенклатура И Склад = &Склад";
	
	// 2. Добавляем характеристику, если она передана
	Если ЗначениеЗаполнено(ХарактеристикаНоменклатура) Тогда
		ТекстФильтра = ТекстФильтра + " И ХарактеристикаНоменклатуры = &Характеристика";
	КонецЕсли;
	
	Запрос = Новый Запрос;
	// Используем СтрШаблон или конкатенацию для вставки фильтра в параметры виртуальной таблицы
	Запрос.Текст = 
	"ВЫБРАТЬ
	|	ЕСТЬNULL(ТоварыНаСкладахОстатки.КоличествоОстаток, 0) КАК Остаток
	|ИЗ
	|	РегистрНакопления.ТоварыНаСкладах.Остатки(" + ТекстФильтра + ") КАК ТоварыНаСкладахОстатки";
	
	Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
	Запрос.УстановитьПараметр("Склад", Склад);
	
	Если ЗначениеЗаполнено(ХарактеристикаНоменклатура) Тогда
		Запрос.УстановитьПараметр("Характеристика", ХарактеристикаНоменклатура);
	КонецЕсли;
	
	Выборка = Запрос.Выполнить().Выбрать();
	
	Возврат ?(Выборка.Следующий(), Выборка.Остаток, 0);
КонецФункции
```

### Verification

1.  **Сценарий А: Переданы только Номенклатура и Склад.**
    *   `ХарактеристикаНоменклатура` принимает значение `Неопределено`.
    *   `ТекстФильтра` остается `"Номенклатура = &Номенклатура И Склад = &Склад"`.
    *   Результат: возвращается сумма остатков по всем характеристикам данной номенклатуры на складе (поведение как в исходной функции).
2.  **Сценарий Б: Переданы все три параметра.**
    *   `ЗначениеЗаполнено(ХарактеристикаНоменклатура)` возвращает `Истина`.
    *   В фильтр добавляется условие по характеристике.
    *   Результат: возвращается остаток конкретной характеристики.
3.  **Сценарий В: Пустая ссылка или Неопределено в характеристике.**
    *   `ЗначениеЗаполнено` отсекает пустые значения, предотвращая некорректную фильтрацию по «пустой» характеристике, если она не была задумана.
4.  **Сложность**:
    *   Временная сложность: $O(1)$ (индексный поиск по виртуальной таблице).
    *   Память: минимальное выделение под строку запроса.

### Confidence
HIGH — Использован стандартный паттерн динамического формирования параметров виртуальных таблиц 1С, что гарантирует оптимальный план выполнения SQL-запроса.
