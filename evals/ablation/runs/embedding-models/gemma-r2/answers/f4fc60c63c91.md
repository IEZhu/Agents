### Analysis
The task requires implementing a validation function for Russian Taxpayer Identification Numbers (INN). The core requirements are:
1. **Input Filtering**: Reject any string that is not composed strictly of digits, including empty strings and those containing spaces.
2. **Length Validation**: Only strings of length 10 (legal entities) and 12 (individuals) are acceptable.
3. **Checksum Verification**: Implement the FNS (Federal Tax Service) algorithm, which uses weighted sums and modulo 11 arithmetic. For both 10 and 12-digit INNs, if the remainder of the division by 11 is 10, the control digit is considered 0.

### Implementation

```python
from typing import List

def validate_inn(inn: str) -> bool:
    """
    Validates a Russian INN (Taxpayer Identification Number).
    Supports 10-digit (legal entities) and 12-digit (individuals) formats.
    """
    # 1. Basic validation: non-empty, digits only
    if not inn or not inn.isdigit():
        return False

    length = len(inn)
    
    # 2. Length validation
    if length not in (10, 12):
        return False

    # Convert string to list of integers for calculation
    digits = [int(d) for d in inn]

    def calculate_checksum(data: List[int], weights: List[int]) -> int:
        """Calculates the control digit based on FNS weighted sum algorithm."""
        weighted_sum = sum(d * w for d, w in zip(data, weights))
        remainder = weighted_sum % 11
        return 0 if remainder == 10 else remainder

    if length == 10:
        # Weights for legal entities (first 9 digits)
        weights = [2, 4, 10, 3, 5, 9, 4, 6, 8]
        return calculate_checksum(digits[:9], weights) == digits[9]

    if length == 12:
        # Individual INNs have two check digits.
        
        # First check digit (11th digit)
        weights_1 = [7, 2, 4, 10, 3, 5, 9, 4, 6, 8]
        if calculate_checksum(digits[:10], weights_1) != digits[10]:
            return False
        
        # Second check digit (12th digit)
        weights_2 = [3, 7, 2, 4, 10, 3, 5, 9, 4, 6, 8]
        return calculate_checksum(digits[:11], weights_2) == digits[11]

    return False

def test_validate_inn():
    # Test cases: (inn_string, expected_result, description)
    test_cases = [

        ("500100515201", True, "Valid 12-digit INN"),
        
        # Invalid checksums
        ("7707083894", False, "Invalid 10-digit checksum"),
        ("772752281612", False, "Invalid 12-digit checksum"),
        
        # Invalid characters/format
        ("", False, "Empty string"),
        (" 7707083893", False, "Leading space"),
        ("770708389 3", False, "Internal space"),
        ("770708389A", False, "Contains letter"),
        ("77.07083893", False, "Contains punctuation"),
        
        # Invalid lengths
        ("123456789", False, "Too short (9)"),
        ("12345678901", False, "Wrong length (11)"),
        ("1234567890123", False, "Too long (13)"),
    ]

    passed = 0
    for inn, expected, desc in test_cases:
        result = validate_inn(inn)
        if result == expected:
            passed += 1

    test_validate_inn()
```

### Verification

1.  **Input Handling**: The check `not inn.isdigit()` effectively handles empty strings, spaces, and non-numeric characters, returning `False` as requested.
2.  **Length Constraints**: Explicit checks for `len(inn) not in (10, 12)` ensure only valid Russian INN lengths are processed.
3.  **Algorithm Accuracy**:
    *   **10-digit**: Uses weights `[2, 4, 10, 3, 5, 9, 4, 6, 8]` applied to the first 9 digits.
    *   **12-digit**: Uses two-stage verification. The first check (11th digit) uses weights `[7, 2, 4, 10, 3, 5, 9, 4, 6, 8]`. The second check (12th digit) uses weights `[3, 7, 2, 4, 10, 3, 5, 9, 4, 6, 8]`.
    *   **Remainder 10**: The logic `0 if remainder == 10 else remainder` correctly handles the FNS edge case for the control digit.
4.  **Complexity**: 
    *   **Time**: $O(1)$ since the input length is capped at 12 digits.
    *   **Space**: $O(1)$ as we only store a small list of integers.
