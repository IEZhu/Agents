### Analysis
Для решения этой задачи лучше всего использовать регулярное выражение, которое разделяет проверку на две части: префикс (`+7` или `8`) и основное тело номера (начинающееся с `9` и содержащее еще 9 цифр), разрешая при этом произвольное вкрапление служебных символов (пробелы, скобки, дефисы).

Оптимальный паттерн: `^(\+7|8)[\s\-()]*9([\s\-()]*\d){9}$`

### Implementation

```python
import re

def validate_russian_phone(phone):
    # Регулярное выражение:
    # ^(\+7|8)        - Начинается с +7 или 8
    # [\s\-()]*       - Любое количество пробелов, дефисов или скобок
    # 9               - Обязательная девятка после префикса
    # ([\s\-()]*\d){9} - 9 цифр, каждая из которых может быть preceded служебными символами
    # $               - Конец строки
    pattern = r'^(\+7|8)[\s\-()]*9([\s\-()]*\d){9}$'
    
    if re.match(pattern, phone):
        return True
    return False

# Тестовые случаи
test_cases = [
    # Валидные
    ("+7 912 345-67-89", True),
    ("8 (912) 345-67-89", True),
    ("89123456789", True),
    ("+79123456789", True),
    ("8-912-345-67-89", True),
    ("+7(912)3456789", True),
    
    # Невалидные
    ("+7 812 345-67-89", False), # Начинается с 8 вместо 9
    ("7 912 345-67-89", False),  # Нет + перед 7
    ("8 912 345-67", False),     # Слишком короткий
    ("8 912 345-67-89-0", False), # Слишком длинный
    ("912 345-67-89", False),    # Нет префикса 7 или 8
    ("abc 912 345-67-89", False),# Мусор в начале
]

print(f"{'Номер':<20} | {'Ожидание':<10} | {'Результат':<10}")
print("-" * 45)
for phone, expected in test_cases:
    result = validate_russian_phone(phone)
    status = "✅" if result == expected else "❌"
    print(f"{phone:<20} | {str(expected):<10} | {str(result):<10} {status}")
```

### Verification

1.  **Префиксы**: Проверены `+7` и `8`. Вариант просто `7` (без плюса) отклоняется, так как это не соответствует стандарту.
2.  **Первая цифра**: Условие "начинаться с 9" строго соблюдено (`...9([\s\-()]*\d){9}`).
3.  **Длина**: После префикса строго 10 цифр (9 + еще 9). Лишние или недостающие цифры приводят к `False`.
4.  **Символы**: `[\s\-()]*` позволяет вставлять пробелы, тире и скобки в любом месте между цифрами.
5.  **Сложность**: Временная сложность $\mathcal{O}(n)$, где $n$ — длина строки. Память $\mathcal{O}(1)$.

### Confidence
HIGH — Регулярное выражение покрывает все указанные требования и краевые случаи.
