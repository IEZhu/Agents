### Solution

```sql
WITH RankedOrders AS (
    SELECT 
        id, 
        customer_id, 
        created_at, 
        amount,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id 
            ORDER BY amount DESC, created_at ASC
        ) as rn
    FROM orders
)
SELECT 
    id, 
    customer_id, 
    created_at, 
    amount
FROM RankedOrders
WHERE rn = 2;
```

### Почему этот запрос корректен:

1.  **`ROW_NUMBER()`**: Эта оконная функция присваивает уникальный порядковый номер каждой строке внутри группы. В отличие от `RANK()`, она не создает «пропусков» в нумерации при одинаковых значениях, что гарантирует получение ровно одной строки (второй) для каждого клиента.
2.  **`PARTITION BY customer_id`**: Сбрасывает счетчик для каждого нового клиента, превращая общую таблицу в набор независимых списков заказов по пользователям.
3.  **`ORDER BY amount DESC, created_at ASC`**: Строго реализует ваше условие сортировки внутри каждой группы: сначала самые дорогие заказы, затем самые ранние при равенстве сумм.
4.  **Фильтр `rn = 2`**: 
    *   Выбирает именно второй заказ по заданному порядку.
    *   **Автоматически исключает** клиентов с одним заказом, так как для них максимальное значение `rn` будет равно 1, и условие `rn = 2` не выполнится.

**Рекомендация по производительности:**
Для того чтобы этот запрос работал максимально быстро на больших объемах данных, рекомендуется создать составной индекс:
`CREATE INDEX idx_orders_customer_amount_date ON orders (customer_id, amount DESC, created_at ASC);`
Это позволит PostgreSQL использовать **Index Scan** вместо дорогой сортировки в памяти.
