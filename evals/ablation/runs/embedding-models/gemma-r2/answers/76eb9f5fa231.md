### Analysis
Вы столкнулись с одной из самых известных ловушек в Python — **изменяемыми аргументами по умолчанию (Mutable Default Arguments)**.

Проблема в том, что в Python значения аргументов по умолчанию вычисляются **один раз** в момент определения функции, а не при каждом её вызове. Поскольку список `[]` является изменяемым объектом, Python создает один и тот же экземпляр списка при инициализации функции и переиспользует его при каждом вызове, где аргумент `bucket` не передан.

### Implementation

Чтобы исправить это, следует использовать `None` в качестве значения по умолчанию. Это стандартный паттерн в Python для работы с изменяемыми типами данных.

```python
def add_item(item, bucket=None):
    # Если bucket не передан (равен None), создаем новый список прямо внутри функции
    if bucket is None:
        bucket = []
    
    bucket.append(item)
    return bucket

# Проверка
print(add_item(1))  # Результат: [1] (создан новый список)
print(add_item(2))  # Результат: [2] (создан еще один новый список)

# При этом функция по-прежнему позволяет передать существующий список:
my_list = [10, 20]
print(add_item(3, my_list))  # Результат: [10, 20, 3]
```

### Verification

1.  **Первый вызов `add_item(1)`**: `bucket` равен `None` $\rightarrow$ создается новый список `[]` $\rightarrow$ добавляется `1` $\rightarrow$ возвращается `[1]`.
2.  **Второй вызов `add_item(2)`**: `bucket` снова равен `None` $\rightarrow$ создается **новый** пустой список `[]` $\rightarrow$ добавляется `2` $\rightarrow$ возвращается `[2]`.
3.  **Сложность**: Временная сложность $\mathcal{O}(1)$ для добавления элемента, пространственная $\mathcal{O}(n)$ для хранения списка.

**Почему это работает:**
Теперь создание списка `bucket = []` происходит в теле функции (runtime), а не в её заголовке (definition time). Таким образом, при каждом вызове без аргумента создается свежий объект.
