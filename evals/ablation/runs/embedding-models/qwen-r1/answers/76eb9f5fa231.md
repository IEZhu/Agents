### Analysis

Классическая ловушка Python: **mutable default argument**. Значение по умолчанию `[]` создаётся **один раз** при определении функции, а не при каждом вызове. Все вызовы без явного `bucket` делят один и тот же список.

### Implementation

**Почему так:**

```python
def add_item(item, bucket=[]):   # ← этот [] создаётся ОДИН раз, при def
    bucket.append(item)
    return bucket

add_item(1)  # bucket — тот самый список из def → [1]
add_item(2)  # bucket — ТОТ ЖЕ список, уже [1] → append → [1, 2]
```

Можно убедиться, что это один объект:

```python
a = add_item(1)
b = add_item(2)
print(a is b)  # True — один и тот же список в памяти
```

**Правильный вариант:**

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

Теперь при каждом вызове без `bucket` создаётся **новый** список:

```python
add_item(1)  # [1]
add_item(2)  # [2]  ← новый список, а не [1, 2]
```

### Verification

| Сценарий | `bucket=[]` | `bucket=None` |
|----------|-------------|---------------|
| `add_item(1)` | `[1]` | `[1]` |
| `add_item(2)` | `[1, 2]` ← баг | `[2]` |
| `add_item(3, [10])` | `[10, 3]` | `[10, 3]` |

Паттерн `None` + создание внутри — стандартная идиомата Python (PEP 8, E742 в flake8 как раз ловит `def f(x=[])`).

### Confidence

**HIGH** — поведение mutable defaults задокументировано в Python docs и воспроизводится детерминированно; это не edge case, а базовая семантика языка.
