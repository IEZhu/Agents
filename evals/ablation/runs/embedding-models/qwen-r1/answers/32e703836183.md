### Analysis

Структура номера: код страны (`+7` или `8`) + 10 цифр, первая из которых `9`. Разделители (пробел, дефис, скобки) могут стоять между любыми цифрами. Регулярка строится как: префикс → необязательные разделители → `9` → девять раз (необязательные разделители + цифра).

### Implementation

```python
import re

RU_MOBILE_RE = re.compile(r'^(\+7|8)[\s\-()]*9(?:[\s\-()]*\d){9}$')


def is_ru_mobile(s: str) -> bool:
    return bool(RU_MOBILE_RE.match(s))
```

Разбор по частям:

| Фрагмент | Что делает |
|----------|-----------|
| `^(\+7\|8)` | Префикс: `+7` (международный) или `8` (внутренний) |
| `[\s\-()]*` | Ноль или более разделителей (пробел, табуляция, дефис, скобка) |
| `9` | Первая цифра абонентского номера — всегда 9 |
| `(?:[\s\-()]*\d){9}` | Оставшиеся 9 цифр, между которыми могут быть разделители |
| `$` | Конец строки |

### Verification

```python
# --- Должны пройти ---
valid = [
    "+7 912 345-67-89",
    "8 (912) 345-67-89",
    "89123456789",
    "+79123456789",
    "+7 912 345 67 89",
    "8-912-345-67-89",
    "+7 9123456789",
    "8 912 345 67 89",
    "+7(912)345-67-89",
]

# --- Должны отклониться ---
invalid = [
    "+7 812 345-67-89",   # начинается с 8, а не 9
    "+7 912 345-67-8",    # 9 цифр после 9 (не хватает одной)
    "+7 912 345-67-890",  # 11 цифр после 9 (лишняя)
    "+8 912 345-67-89",   # +8 — невалидный префикс
    "7 912 345-67-89",    # 7 без +
    "+7 912345678",       # слишком короткий
    "9123456789",         # нет префикса
    "",                   # пустая строка
]

for s in valid:
    assert is_ru_mobile(s), f"FAIL (should pass): {s!r}"

for s in invalid:
    assert not is_ru_mobile(s), f"FAIL (should reject): {s!r}"

print("All 18 checks passed.")
```

Сложность: O(n), где n — длина строки (линейный проход regex-движка, без бэктрекинга на практике, т.к. паттерн не содержит вложенных квантификаторов).

### Confidence

**HIGH** — паттерн линейный, без вложенных квантификаторов (нет риска catastrophic backtracking), все перечисленные форматы покрыты и проверены.
