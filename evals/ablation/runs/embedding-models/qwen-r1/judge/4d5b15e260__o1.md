Нужна регулярка (Python, re) для проверки российского мобильного номера. Должны проходить варианты вроде +7 912 345-67-89, 8 (912) 345-67-89, 89123456789 и +79123456789: пробелы, скобки и дефисы необязательны. Номер после +7 или 8 должен начинаться с 9. Дай регулярку и несколько проверок.

## Rubric (what a strong answer does)
1. The pattern accepts all four examples from the request.
2. It requires +7 or 8, then 9, then nine more digits, and rejects a wrong digit count or a first digit other than 9.
3. It is anchored to the whole string (re.fullmatch or ^...\Z) and comes with a few test cases.
4. The reply is in Russian, with code, commands and identifiers left as written, and contains no English restatement of the request.

## Answer A
### Analysis

Структура номера: код страны (`+7` или `8`) + 10 цифр, первая из которых `9`. Разделители (пробел, дефис, скобки) могут стоять между любыми цифрами. Регулярка строится как: префикс → необязательные разделители → `9` → девять раз (необязательные разделители + цифра).

### Implementation

```python
import re

RU_MOBILE_RE = re.compile(r'^(\+7|8)[\s\-()]*9(?:[\s\-()]*\d){9}$')


def is_ru_mobile(s: str) -> bool:
    return bool(RU_MOBILE_RE.match(s))
```

Разбор по частям:

| Фрагмент | Что делает |
|----------|-----------|
| `^(\+7\|8)` | Префикс: `+7` (международный) или `8` (внутренний) |
| `[\s\-()]*` | Ноль или более разделителей (пробел, табуляция, дефис, скобка) |
| `9` | Первая цифра абонентского номера — всегда 9 |
| `(?:[\s\-()]*\d){9}` | Оставшиеся 9 цифр, между которыми могут быть разделители |
| `$` | Конец строки |

## Answer B
### Analysis

Russian mobile number: country code `+7` or `8`, then exactly 10 digits starting with `9`. Separators (spaces, hyphens, parentheses) are optional between any two digits. I'll build the pattern from a reusable "gap" token and verify with a quick test run.

### Implementation

```python
import re

# Gap between any two digits: optional spaces/hyphens, at most one paren, optional spaces/hyphens
_SEP = r'[\s-]*(?:[()])?[\s-]*'

# Country code (+7 or 8), then 10 digits (first must be 9), gaps between every digit
_RU_MOBILE = re.compile(
    rf'(\+7|8)'
    rf'{_SEP}9'
    rf'{_SEP}\d{_SEP}\d{_SEP}\d{_SEP}\d{_SEP}\d{_SEP}\d{_SEP}\d{_SEP}\d{_SEP}\d'
)


def is_russian_mobile(number: str) -> bool:
    """Return True if *number* is a valid Russian mobile number."""
    return _RU_MOBILE.fullmatch(number) is not None
```

**How it works**

| Fragment | Purpose |
|----------|---------|
| `(\+7\|8)` | Country code: `+7` (international) or bare `8` (domestic) |
| `{_SEP}` | Optional `[\s-]*` + one optional `(` or `)` + `[\s-]*` |
| `9` | First subscriber digit must be 9 |
| `\d` × 9 | Remaining 9 digits |
| `fullmatch` | Anchors both ends; no trailing-newline loophole |
