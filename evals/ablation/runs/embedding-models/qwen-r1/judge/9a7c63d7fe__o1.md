## Latest user message
Не понимаю, что происходит. Есть функция:

def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket

add_item(1) возвращает [1], а следующий вызов add_item(2) — уже [1, 2]. Почему так и как правильно написать?

## Rubric (what a strong answer does)

2. Gives the standard fix with a None default (bucket=None, then a new list inside the function) in correct Python.

## Answer A
### Analysis

Классическая ловушка Python: **mutable default argument**. Значение по умолчанию `[]` создаётся **один раз** при определении функции (в момент `def`), а не при каждом вызове. Все вызовы без явного `bucket` делят один и тот же список.

### Implementation

**Почему так:**

```python
def add_item(item, bucket=[]):   # ← этот [] создаётся ОДИН раз, при def
    bucket.append(item)
    return bucket

add_item(1)  # bucket — тот самый список из def → [1]
add_item(2)  # bucket — ТОТ ЖЕ список, уже [1] → append → [1, 2]
```

Можно убедиться, что это один объект:

```python
a = add_item(1)
b = add_item(2)
print(a is b)  # True — оба ссылаются на один и тот же list
```

**Правильный вариант:**

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

Теперь при каждом вызове без `bucket` создаётся **новый** список.

### Verification

```python
print(add_item(1))  # [1]
print(add_item(2))  # [2]  ← новый список, не [1, 2]
```

### Confidence

**HIGH** — поведение mutable default arguments задокументировано в Python docs и воспроизводится детерминированно; это не баг, а осознанный дизайн (default-аргументы вычисляются один раз при компиляции функции).

| Сценарий | `bucket=[]` | `bucket=None` |

| `add_item(3, [10])` | `[10, 3]` | `[10, 3]` |
