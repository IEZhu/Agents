### Analysis
Для решения задачи потребуется регулярное выражение, которое гибко обрабатывает разделители (пробелы, скобки, дефисы), но строго контролирует структуру цифр: префикс (`+7` или `8`), обязательную девятку в начале кода оператора и общее количество цифр (11).

Я выбрал структуру, которая позволяет разделителям стоять в типичных местах, но не допускает произвольного вкрапления символов в середину чисел.

### Implementation

```python
import re

def validate_russian_phone(phone):
    # Регулярное выражение:
    # ^(\+7|8)          - Начинается с +7 или 8
    # [\s\-()]*         - Опциональные разделители (пробел, дефис, скобки)
    # 9                 - Обязательная девятка
    # \d{2}             - Еще две цифры кода оператора (итого 3 цифры: 9xx)
    # [\s\-()]*         - Опциональные разделители
    # \d{3}             - Три цифры номера
    # [\s\-()]*         - Опциональные разделители
    # \d{2}             - Две цифры номера
    # [\s\-()]*         - Опциональные разделители
    # \d{2}             - Последние две цифры номера
    # $                 - Конец строки
    pattern = r'^(\+7|8)[\s\-()]*9\d{2}[\s\-()]*\d{3}[\s\-()]*\d{2}[\s\-()]*\d{2}$'
    
    return bool(re.match(pattern, phone))

# --- Тесты ---
test_cases = {
    "+7 912 345-67-89": True,   # Стандартный с пробелами и дефисами
    "8 (912) 345-67-89": True,  # Со скобками
    "89123456789": True,        # Слитно через 8
    "+79123456789": True,       # Слитно через +7
    "+7(912)3456789": True,     # Смешанный вариант
    
    "+7 812 345-67-89": False,  # Ошибка: начинается с 8 (не мобильный)
    "7 912 345-67-89": False,   # Ошибка: нет + перед 7
    "8 912 345-67-8": False,    # Ошибка: слишком короткий
    "8 912 345-67-890": False,  # Ошибка: слишком длинный
    "abc 912 345-67-89": False, # Ошибка: буквы
}

print(f"{'Phone Number':<20} | {'Expected':<10} | {'Result':<10}")
print("-" * 45)
for phone, expected in test_cases.items():
    result = validate_russian_phone(phone)
    status = "✅" if result == expected else "❌"
    print(f"{phone:<20} | {str(expected):<10} | {str(result):<10} {status}")
```

### Verification

1.  **Корректность**: Регулярка проверяет именно 11 цифр. Префикс `(\+7|8)` и последующая `9` гарантируют соответствие российским мобильным стандартам.
2.  **Гибкость**: Использование `[\s\-()]*` между группами цифр позволяет пользователю вводить номер в любом привычном формате (с пробелами, скобками или без них).
3.  **Безопасность**: Якоря `^` и `$` предотвращают частичное совпадение (например, если в строке будет 15 цифр, проверка не пройдет).
4.  **Сложность**: Временная сложность $O(N)$, где $N$ — длина строки. Память $O(1)$.

### Confidence
HIGH — Регулярное выражение протестировано на всех указанных кейсах и покрывает основные краевые случаи (длина, префикс, первая цифра кода).
