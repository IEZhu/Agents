```sql
WITH RankedOrders AS (
    SELECT 
        id, 
        customer_id, 
        created_at, 
        amount,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id 
            ORDER BY amount DESC, created_at ASC
        ) as rn
    FROM orders
)
SELECT id, customer_id, created_at, amount
FROM RankedOrders
WHERE rn = 2;
```

### Почему запрос корректен:

1.  **`ROW_NUMBER()`**: Эта оконная функция присваивает уникальный порядковый номер каждой строке внутри группы. В отличие от `RANK()`, она не создает «дыр» в нумерации при одинаковых значениях, что гарантирует получение именно одной (второй) строки.
2.  **`PARTITION BY customer_id`**: Сбрасывает счетчик для каждого нового клиента, позволяя нумеровать заказы индивидуально для каждого `customer_id`.
3.  **`ORDER BY amount DESC, created_at ASC`**: Строго реализует заданную бизнес-логику сортировки: сначала по сумме (от большей к меньшей), затем по дате (от старых к новым).
4.  **`WHERE rn = 2`**: 
    *   Выбирает именно второй заказ в отсортированном списке.
    *   Автоматически исключает клиентов с одним заказом, так как для них максимальное значение `rn` будет равно 1.
