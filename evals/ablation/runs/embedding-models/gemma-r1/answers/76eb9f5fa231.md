### Analysis
Вы столкнулись с одной из самых известных особенностей Python — **изменяемыми аргументами по умолчанию (Mutable Default Arguments)**. 

Проблема в том, что в Python значения аргументов по умолчанию вычисляются **один раз в момент определения функции**, а не при каждом её вызове. Список `bucket=[]` создается один раз и сохраняется внутри объекта функции. Все последующие вызовы, в которых вы не передали свой список, используют один и тот же объект списка в памяти.

### Implementation

#### Как это работает сейчас (ошибка):
```python
def add_item(item, bucket=[]): # Список создается ОДИН РАЗ при загрузке кода
    bucket.append(item)        # Вы модифицируете этот единственный общий список
    return bucket
```

#### Как написать правильно:
Чтобы функция создавала новый список при каждом вызове, нужно использовать `None` в качестве значения по умолчанию и инициализировать список внутри тела функции.

```python
def add_item(item, bucket=None):
    # Если bucket не передан, создаем новый пустой список прямо сейчас
    if bucket is None:
        bucket = []
    
    bucket.append(item)
    return bucket

# Проверка:
print(add_item(1)) # [1]
print(add_item(2)) # [2] - теперь работает корректно
print(add_item(3, [10, 20])) # [10, 20, 3] - работает и с переданным списком
```

### Verification
1. **Первый вызов `add_item(1)`**: `bucket` равен `None` $\rightarrow$ создается новый список `[]` $\rightarrow$ добавляется `1` $\rightarrow$ результат `[1]`.
2. **Второй вызов `add_item(2)`**: `bucket` снова равен `None` $\rightarrow$ создается **еще один новый** список `[]` $\rightarrow$ добавляется `2` $\rightarrow$ результат `[2]`.
3. **Сложность**: Временная сложность $O(1)$, пространственная $O(n)$ для хранения результата.

### Confidence
HIGH — это стандартный паттерн проектирования в Python для работы с изменяемыми типами данных (списки, словари, множества) в аргументах функций.
