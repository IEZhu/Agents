### Analysis
Для решения задачи потребуется регулярное выражение, которое учитывает два варианта префикса (`+7` или `8`), строгое начало кода оператора с цифры `9` и допустимые разделители (пробелы, скобки, дефисы), которые могут встречаться в разных местах или отсутствовать вовсе.

**Логика регулярного выражения:**
1. `^(\+7|8)` — начало строки, префикс либо `+7`, либо `8`.
2. `[\s\-()]*` — любое количество (или отсутствие) разделителей.
3. `9\d{2}` — цифра `9` и еще две цифры (код оператора).
4. `[\s\-()]*` — разделители.
5. `\d{3}` — первые три цифры номера.
6. `[\s\-()]*` — разделители.
7. `\d{2}` — следующие две цифры.
8. `[\s\-()]*` — разделители.
9. `\d{2}$` — последние две цифры и конец строки.

### Implementation

```python
import re

def validate_russian_phone(phone: str) -> bool:
    # Регулярное выражение
    # ^(\+7|8)       - начинается с +7 или 8
    # [\s\-()]*      - возможные разделители
    # 9\d{2}         - код оператора (начинается с 9, всего 3 цифры)
    # [\s\-()]*\d{3} - разделители и первые 3 цифры номера
    # [\s\-()]*\d{2} - разделители и следующие 2 цифры
    # [\s\-()]*\d{2} - разделители и последние 2 цифры
    pattern = r'^(\+7|8)[\s\-()]*9\d{2}[\s\-()]*\d{3}[\s\-()]*\d{2}[\s\-()]*\d{2}$'
    
    return bool(re.match(pattern, phone))

# --- Тесты ---
test_cases = {
    "+7 912 345-67-89": True,
    "8 (912) 345-67-89": True,
    "89123456789": True,
    "+79123456789": True,
    "8 912 345 67 89": True,
    "+7(912)3456789": True,
    # Отрицательные кейсы
    "+7 812 345-67-89": False, # Код начинается не с 9
    "7 912 345-67-89": False,  # Нет + перед 7
    "8 912 345-67-8": False,   # Слишком короткий
    "+7 912 345-67-890": False, # Слишком длинный
    "abc 912 345-67-89": False, # Не цифры
}

print(f"{'Phone Number':<20} | {'Expected':<10} | {'Result':<10}")
print("-" * 45)
for phone, expected in test_cases.items():
    result = validate_russian_phone(phone)
    status = "✅" if result == expected else "❌"
    print(f"{phone:<20} | {str(expected):<10} | {str(result):<10} {status}")
```

### Verification
1. **Позитивные сценарии**: Все указанные в ТЗ форматы (`+7...`, `8...`, со скобками и без) проходят проверку, так как разделители помечены квантификатором `*` (0 или более).
2. **Валидация кода**: Условие "номер должен начинаться с 9" реализовано через `9\d{2}` сразу после префикса.
3. **Длина**: Регулярка строго ограничивает количество цифр (1 префикс + 10 цифр номера), что предотвращает пропуск слишком коротких или длинных строк.
4. **Сложность**: Временная сложность проверки — $O(N)$, где $N$ — длина строки.

### Confidence
HIGH — Регулярное выражение покрывает все граничные условия, описанные в запросе, и протестировано на наборе валидных и невалидных данных.
