### Analysis
Для реализации этой задачи необходимо использовать особенность виртуальных таблиц остатков в 1С: если измерение не указано в параметрах фильтра виртуальной таблицы, система автоматически суммирует данные по всем значениям этого измерения.

Таким образом, нам нужно:
1. Добавить необязательный параметр `Характеристика` в функцию.
2. Динамически формировать строку фильтра для виртуальной таблицы `Остатки`.
3. Устанавливать параметр запроса только в том случае, если характеристика была передана и заполнена.

### Implementation

```bsl
Функция ПолучитьОстатокТовара(Номенклатура, Склад, Характеристика = Неопределено) Экспорт
	
	Запрос = Новый Запрос;
	
	// Формируем базовый фильтр
	ТекстФильтра = "Номенклатура = &Номенклатура И Склад = &Склад";
	
	// Если характеристика передана и она не пустая, добавляем её в фильтр
	Если ЗначениеЗаполнено(Характеристика) Тогда
		ТекстФильтра = ТекстФильтра + " И Характеристика = &Характеристика";
	КонецЕсли;
	
	Запрос.Текст = 
	"ВЫБРАТЬ
	|	ЕСТЬNULL(ТоварыНаСкладахОстатки.КоличествоОстаток, 0) КАК Остаток
	|ИЗ
	|	РегистрНакопления.ТоварыНаСкладах.Остатки(, " + ТекстФильтра + ") КАК ТоварыНаСкладахОстатки";
	
	Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
	Запрос.УстановитьПараметр("Склад", Склад);
	
	Если ЗначениеЗаполнено(Характеристика) Тогда
		Запрос.УстановитьПараметр("Характеристика", Характеристика);
	КонецЕсли;
	
	Выборка = Запрос.Выполнить().Выбрать();
	Возврат ?(Выборка.Следующий(), Выборка.Остаток, 0);
	
КонецФункции
```

### Verification
1. **Обратная совместимость**: Если функция вызывается как `ПолучитьОстатокТовара(Ном, Скл)`, параметр `Характеристика` принимает значение `Неопределено`. Условие `ЗначениеЗаполнено` возвращает `Ложь`, фильтр остается прежним, и возвращается сумма остатков по всем характеристикам.
2. **Фильтрация по характеристике**: Если передана конкретная характеристика, она добавляется в условие виртуальной таблицы, и запрос возвращает остаток только по ней.
3. **Производительность**: Использование фильтра в параметрах виртуальной таблицы (`Остатки(, "Фильтр")`) является наиболее оптимальным способом получения данных в 1С, так как отсечение данных происходит на уровне СУБД до формирования итоговой выборки.
4. **Безопасность**: Параметры передаются через `УстановитьПараметр`, что исключает возможность SQL-инъекций.

HIGH — Решение использует стандартные механизмы платформы 1С:Предприятие 8 и полностью соответствует требованиям.
