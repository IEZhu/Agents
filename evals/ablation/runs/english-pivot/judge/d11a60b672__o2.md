## Answer A
### Analysis

The spec asks for `validate_inn(inn: str) -> bool`. It must accept a 10-digit legal-entity INN or a 12-digit individual INN only when the FNS check digits match, and reject everything else. The one design decision that matters is how input gets screened. I use `re.fullmatch(r"[0-9]{10}|[0-9]{12}", inn)` instead of `str.isdigit()` or `\d`, because both of those accept non-ASCII digits such as `"７"` (fullwidth) or `"²"`, and the spec rejects any character that is not a digit. `fullmatch` also rejects a trailing `"\n"`, which `re.match(r"...$")` would let through.

Check-digit algorithm (FNS weights):
- **10 digits**: weights `2 4 10 3 5 9 4 6 8` over digits 1–9. Check = `(sum % 11) % 10` and must equal digit 10.
- **12 digits**: weights `7 2 4 10 3 5 9 4 6 8` over digits 1–10 give digit 11. Then weights `3 7 2 4 10 3 5 9 4 6 8` over digits 1–11 give digit 12. Each one uses the same `(sum % 11) % 10` reduction.

### Implementation

```python
# inn.py
import re

_INN_FORMAT = re.compile(r"[0-9]{10}|[0-9]{12}")

_WEIGHTS_10 = (2, 4, 10, 3, 5, 9, 4, 6, 8)
_WEIGHTS_12_FIRST = (7, 2, 4, 10, 3, 5, 9, 4, 6, 8)
_WEIGHTS_12_SECOND = (3, 7, 2, 4, 10, 3, 5, 9, 4, 6, 8)


def _check_digit(digits: list[int], weights: tuple[int, ...]) -> int:
    """FNS control digit: weighted sum mod 11, then mod 10 (so 10 becomes 0)."""
    return sum(d * w for d, w in zip(digits, weights)) % 11 % 10


def validate_inn(inn: str) -> bool:
    """Validate a Russian INN (10 digits for legal entities, 12 for individuals)."""
    if not _INN_FORMAT.fullmatch(inn):
        return False

    digits = [int(ch) for ch in inn]

    if len(digits) == 10:
        return _check_digit(digits, _WEIGHTS_10) == digits[9]

    return (
        _check_digit(digits, _WEIGHTS_12_FIRST) == digits[10]
        and _check_digit(digits, _WEIGHTS_12_SECOND) == digits[11]
    )
```

A non-`str` argument such as `None` raises `TypeError` from `re.fullmatch` and does not return `False`. That is a deliberate fail-fast choice because the signature promises `str`. If your callers pass raw untyped data, add an `isinstance(inn, str)` guard at the top.

## Answer B
### Analysis
The spec asks for `validate_inn(inn: str) -> bool`. It accepts a 10-digit INN (legal entity) or a 12-digit INN (individual) and checks the control digits with the FNS weighted-checksum algorithm. Anything else returns `False`. I made two choices the spec does not cover:

- **Digit check.** "Digit" means ASCII `0-9` only. `str.isdigit()` also accepts characters like `"²"` and full-width `"７"`, so it would let non-ASCII digits through.
- **Wrong input type.** A non-`str` argument raises `TypeError` rather than returning `False`. That is a caller bug, not an invalid INN. If your team prefers `False`, change one line.

### Implementation

`inn.py`
```python
import re

_INN_PATTERN = re.compile(r"[0-9]{10}|[0-9]{12}")

_WEIGHTS_10 = (2, 4, 10, 3, 5, 9, 4, 6, 8)
_WEIGHTS_12_FIRST = (7, 2, 4, 10, 3, 5, 9, 4, 6, 8)
_WEIGHTS_12_SECOND = (3, 7, 2, 4, 10, 3, 5, 9, 4, 6, 8)


def _control_digit(digits: list[int], weights: tuple[int, ...]) -> int:
    # FNS rule: weighted sum mod 11; a remainder of 10 becomes 0.
    return sum(d * w for d, w in zip(digits, weights)) % 11 % 10


def validate_inn(inn: str) -> bool:
    """Return True if `inn` is a valid Russian INN (10 or 12 ASCII digits with correct check digits)."""
    if not isinstance(inn, str):
        raise TypeError(f"inn must be str, got {type(inn).__name__}")
    if not _INN_PATTERN.fullmatch(inn):
        return False

    digits = [int(ch) for ch in inn]
    if len(digits) == 10:
        return _control_digit(digits, _WEIGHTS_10) == digits[9]
    return (
        _control_digit(digits, _WEIGHTS_12_FIRST) == digits[10]
        and _control_digit(digits, _WEIGHTS_12_SECOND) == digits[11]
    )
```

Notes:
- **Why `fullmatch`.** It rejects leading and trailing whitespace, including a trailing `"\n"`, which a `^...$` pattern would let through. That covers the spec's "spaces → False" rule without stripping input.
- **How the algorithm works.** In a 12-digit INN, digit 11 is computed from the first 10 digits, and digit 12 from the first 11 (including digit 11).
