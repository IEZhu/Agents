Регулярка для `re.fullmatch` (поэтому якоря `^`/`$` не нужны):

```python
import re

RU_MOBILE_RE = re.compile(
    r"""
    (?:\+7|8)            # код страны: +7 или 8
    [ -]?                # необязательный разделитель
    (?:\(9\d{2}\)|9\d{2})  # код оператора 9XX, либо целиком в скобках, либо без них
    [ -]?
    \d{3}
    [ -]?
    \d{2}
    [ -]?
    \d{2}
    """,
    re.VERBOSE,
)


def is_ru_mobile(phone: str) -> bool:
    return RU_MOBILE_RE.fullmatch(phone) is not None
```

Однострочный вариант:

```python
r"(?:\+7|8)[ -]?(?:\(9\d{2}\)|9\d{2})[ -]?\d{3}[ -]?\d{2}[ -]?\d{2}"
```

Почему именно так:

- Скобки сделаны альтернативой `\(9\d{2}\)|9\d{2}`, а не через `\(?9\d{2}\)?`. Иначе прошли бы номера с одной скобкой, например `8 (912 345-67-89`.
- `fullmatch` вместо `match` с `$`: в Python `$` совпадает и перед завершающим `\n`, так что строка `"89123456789\n"` прошла бы проверку.
- Разделитель — только пробел или дефис, и не больше одного между группами. Если нужно разрешить табы или двойные пробелы, замените `[ -]?` на `[\s-]*`.

Проверки:

```python
valid = [
    "+7 912 345-67-89",
    "8 (912) 345-67-89",
    "89123456789",
    "+79123456789",
    "+7(912)3456789",
    "8-912-345-67-89",
]

invalid = [
    "+7 812 345-67-89",    # код не начинается с 9
    "8 (912 345-67-89",    # незакрытая скобка
    "8 912) 345-67-89",    # лишняя закрывающая скобка
    "7 912 345-67-89",     # 7 без плюса
    "+8 912 345-67-89",    # неверный код страны
    "8912345678",          # 10 цифр
    "891234567890",        # 12 цифр
    "89123456789\n",       # завершающий перевод строки
    "8  912 345 67 89",    # двойной пробел
    "",
]

for p in valid:
    assert is_ru_mobile(p), f"должен пройти: {p!r}"
for p in invalid:
    assert not is_ru_mobile(p), f"не должен пройти: {p!r}"
print("ok")
```

Обратите внимание: регулярка проверяет только формат номера. Существует ли такой номер, она не проверяет. Если дальше номер нужно хранить, лучше привести его к одному виду: убрать все нецифровые символы и заменить ведущую `8` на `7`.
