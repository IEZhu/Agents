### Analysis
The spec asks for `validate_inn(inn: str) -> bool`. It accepts a 10-digit INN (legal entity) or a 12-digit INN (individual) and checks the control digits with the FNS weighted-checksum algorithm. Anything else returns `False`. I made two choices the spec does not cover:

- **Digit check.** "Digit" means ASCII `0-9` only. `str.isdigit()` also accepts characters like `"²"` and full-width `"７"`, so it would let non-ASCII digits through.
- **Wrong input type.** A non-`str` argument raises `TypeError` rather than returning `False`. That is a caller bug, not an invalid INN. If your team prefers `False`, change one line.

### Implementation

`inn.py`
```python
import re

_INN_PATTERN = re.compile(r"[0-9]{10}|[0-9]{12}")

_WEIGHTS_10 = (2, 4, 10, 3, 5, 9, 4, 6, 8)
_WEIGHTS_12_FIRST = (7, 2, 4, 10, 3, 5, 9, 4, 6, 8)
_WEIGHTS_12_SECOND = (3, 7, 2, 4, 10, 3, 5, 9, 4, 6, 8)


def _control_digit(digits: list[int], weights: tuple[int, ...]) -> int:
    # FNS rule: weighted sum mod 11; a remainder of 10 becomes 0.
    return sum(d * w for d, w in zip(digits, weights)) % 11 % 10


def validate_inn(inn: str) -> bool:
    """Return True if `inn` is a valid Russian INN (10 or 12 ASCII digits with correct check digits)."""
    if not isinstance(inn, str):
        raise TypeError(f"inn must be str, got {type(inn).__name__}")
    if not _INN_PATTERN.fullmatch(inn):
        return False

    digits = [int(ch) for ch in inn]
    if len(digits) == 10:
        return _control_digit(digits, _WEIGHTS_10) == digits[9]
    return (
        _control_digit(digits, _WEIGHTS_12_FIRST) == digits[10]
        and _control_digit(digits, _WEIGHTS_12_SECOND) == digits[11]
    )
```

Notes:
- **Why `fullmatch`.** It rejects leading and trailing whitespace, including a trailing `"\n"`, which a `^...$` pattern would let through. That covers the spec's "spaces → False" rule without stripping input.
- **How the algorithm works.** In a 12-digit INN, digit 11 is computed from the first 10 digits, and digit 12 from the first 11 (including digit 11).

`test_inn.py` (pytest)
```python
import pytest

from inn import validate_inn


@pytest.mark.parametrize("inn", [
    "7707083893",    # 10-digit, remainder 3
    "5000000000",    # 10-digit, remainder 10 -> control digit 0
    "500100732259",  # 12-digit, both control digits correct
])
def test_valid_inn(inn):
    assert validate_inn(inn) is True


@pytest.mark.parametrize("inn", [
    "7707083894",    # wrong control digit (10)
    "500100732269",  # wrong 11th digit (12)
    "500100732258",  # wrong 12th digit (12)
])
def test_wrong_control_digits(inn):
    assert validate_inn(inn) is False


@pytest.mark.parametrize("inn", [
    "",
    "   ",
    " 7707083893",
    "7707083893 ",
    "7707083893\n",
    "77070-83893",
    "770708389a",
    "７７０７０８３８９３",  # full-width digits: isdigit() would accept these
])
def test_empty_whitespace_and_non_digits(inn):
    assert validate_inn(inn) is False


@pytest.mark.parametrize("inn", ["123456789", "12345678901", "1234567890123"])
def test_wrong_length(inn):
    assert validate_inn(inn) is False


def test_non_str_raises_type_error():
    with pytest.raises(TypeError):
        validate_inn(7707083893)
```

### Verification
- **Test cases checked by hand.**
  - `7707083893`: weighted sum 267, and 267 mod 11 = 3, which matches the last digit.
  - `500100732259`: first check 148 mod 11 = 5, which matches digit 11. Second check 141 mod 11 = 9, which matches digit 12.
  - `5000000000`: weighted sum 10, so the remainder is 10 and the control digit is 0. This exercises the `% 10` branch.
- **Not run.** I didn't execute these tests in this environment. Run `pytest test_inn.py` before merging.
- **Algorithm source.** The weights and the remainder-10 rule are the standard FNS algorithm as I recall it. Please check them against the source your team used for the spec.
- **All-zero INNs.** `"0000000000"` and `"000000000000"` pass the checksum. The spec doesn't exclude them. If you need to reject them, the FNS checksum alone won't do it, so add a separate rule.
- **Complexity:** O(n) with n ≤ 12, so effectively constant.
