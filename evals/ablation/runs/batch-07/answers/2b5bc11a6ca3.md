## Две оговорки

- **Я не сверял эти пункты с внешними источниками.** Всё выше опирается только на ваши данные. По правилам дайджеста каждое событие должно подтверждаться двумя независимыми источниками. Перед отправкой стоит найти второй источник для ОФЗ (например, сайт Минфина с итогами аукциона) и для ФРС (сайт federalreserve.gov).

Если так, то материал Reuters от 23.09 может быть не о решении по ставке, а о комментарии кого-то из членов ФРС. Тогда формулировку в дайджесте нужно поправить.
