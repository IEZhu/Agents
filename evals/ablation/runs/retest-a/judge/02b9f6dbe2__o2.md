## Latest user message
Делаю магазин мечей в Roblox. В LocalScript на кнопке "Купить" делаю так: BuyEvent:FireServer("FireSword", 250), где 250 это цена из GUI. На сервере:

BuyEvent.OnServerEvent:Connect(function(player, itemName, price)
    local coins = player.leaderstats.Coins
    if coins.Value >= price then
        coins.Value -= price
        game.ServerStorage.Swords[itemName]:Clone().Parent = player.Backpack
    end
end)

Всё работает, но хочу ещё добавить скидку 20% для VIP (у меня есть gamepass). Куда лучше вставить проверку скидки — в LocalScript при отображении цены или на сервере? Скинь исправленный код.

## Rubric (what a strong answer does)
1. Указывает, что цену нельзя принимать от клиента (эксплойтер может отправить 0 или отрицательное значение), и в коде сервер берёт цену из собственной таблицы/конфига по имени предмета
2. Проверяет на сервере itemName (тип string и существование предмета в каталоге/ServerStorage) до выдачи
3. Скидка VIP вычисляется на сервере через проверку gamepass (например, MarketplaceService:UserOwnsGamePassAsync, обёрнутую в pcall), а клиент лишь отображает цену
4. Приведённый код корректен для Luau и отвечает на заданный вопрос о месте проверки скидки

## Answer A
Скидку нужно считать **только на сервере**. Клиент может лишь *показывать* цену со скидкой.

Но сначала о главном. В текущем коде есть дыра посерьёзнее скидки: **цену присылает клиент**. Эксплойтер вызовет `BuyEvent:FireServer("FireSword", 0)` и получит меч бесплатно. А с `-1000000` проверка `coins.Value >= price` пройдёт, и после `coins.Value -= price` монет у него станет на миллион *больше*. Всё, что приходит из LocalScript, игрок может подделать. Поэтому правило такое: клиент говорит только **что** хочет купить, а **сколько это стоит** решает сервер.

Если добавить скидку в LocalScript при текущей схеме, эксплойтер просто пришлёт цену со скидкой, и никакого VIP ему не понадобится.

## Исправленная схема

### 1. Общий конфиг: `ReplicatedStorage > ShopConfig` (ModuleScript)

Цены лежат в одном месте. Сервер берёт их для расчёта, клиент для отображения. Подменить серверную копию клиент не может.

```lua
-- ReplicatedStorage/ShopConfig
local ShopConfig = {}

ShopConfig.VIP_GAMEPASS_ID = 123456789 -- замени на ID своего gamepass
ShopConfig.VIP_DISCOUNT = 0.2          -- 20%

ShopConfig.Swords = {
	FireSword = 250,
	-- IceSword = 400,
}

function ShopConfig.getPrice(basePrice: number, isVip: boolean): number
	if isVip then
		return math.round(basePrice * (1 - ShopConfig.VIP_DISCOUNT))
	end
	return basePrice
end

return ShopConfig
```

### 2. Сервер: `ServerScriptService > ShopServer` (Script)

```lua
local Players = game:GetService("Players")
local MarketplaceService = game:GetService("MarketplaceService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerStorage = game:GetService("ServerStorage")

local ShopConfig = require(ReplicatedStorage.ShopConfig)
local BuyEvent = ReplicatedStorage.BuyEvent -- поправь путь под свой проект

-- Кэш владения VIP: UserOwnsGamePassAsync ходит в сеть, не дёргаем его на каждую покупку
local vipCache: { [Player]: boolean } = {}

local function isVip(player: Player): boolean
	local cached = vipCache[player]
	if cached ~= nil then
		return cached
	end

	local ok, owns = pcall(function()
		return MarketplaceService:UserOwnsGamePassAsync(player.UserId, ShopConfig.VIP_GAMEPASS_ID)
	end)
	if not ok then
		warn("VIP check failed for", player.Name, owns)
		return false -- ошибку не кэшируем, в следующий раз попробуем снова
	end

	vipCache[player] = owns
	player:SetAttribute("IsVIP", owns) -- чтобы клиент мог показать цену со скидкой
	return owns
end

Players.PlayerAdded:Connect(isVip)
Players.PlayerRemoving:Connect(function(player)
	vipCache[player] = nil
end)

-- Если игрок купил gamepass прямо в текущей сессии
MarketplaceService.PromptGamePassPurchaseFinished:Connect(function(player, gamePassId, wasPurchased)
	if wasPurchased and gamePassId == ShopConfig.VIP_GAMEPASS_ID then
		vipCache[player] = true
		player:SetAttribute("IsVIP", true)
	end
end)

BuyEvent.OnServerEvent:Connect(function(player: Player, itemName: any)
	-- Проверяем всё, что пришло от клиента
	if typeof(itemName) ~= "string" then
		return
	end

	local basePrice = ShopConfig.Swords[itemName]
	local swordTemplate = ServerStorage.Swords:FindFirstChild(itemName)
	if not basePrice or not swordTemplate then
		return
	end

	local price = ShopConfig.getPrice(basePrice, isVip(player))

	-- isVip может уступить поток (сетевой запрос), так что игрок мог уже выйти
	if not player.Parent then
		return
	end

	local leaderstats = player:FindFirstChild("leaderstats")
	local coins = leaderstats and leaderstats:FindFirstChild("Coins")
	if not coins or coins.Value < price then
		return
	end

	coins.Value -= price
	swordTemplate:Clone().Parent = player.Backpack
end)
```

### 3. Клиент: LocalScript на кнопке

```lua
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local ShopConfig = require(ReplicatedStorage.ShopConfig)
local BuyEvent = ReplicatedStorage.BuyEvent

local player = Players.LocalPlayer
local button = script.Parent
local ITEM_NAME = "FireSword"

-- Только отображение: реальную цену всё равно считает сервер
local function updatePriceLabel()
	local isVip = player:GetAttribute("IsVIP") == true
	local price = ShopConfig.getPrice(ShopConfig.Swords[ITEM_NAME], isVip)
	button.Text = isVip and `Купить — {price} (VIP -20%)` or `Купить — {price}`
end

updatePriceLabel()
player:GetAttributeChangedSignal("IsVIP"):Connect(updatePriceLabel)

button.Activated:Connect(function()
	BuyEvent:FireServer(ITEM_NAME) -- цену больше НЕ передаём
end)
```

## Почему так

- **Сервер — единственный источник правды.** И базовая цена, и скидка считаются там. Клиент может поменять себе текст на кнопке, но заплатит всё равно столько, сколько решил сервер.
- **Общий `ShopConfig`** означает, что цена в GUI и на сервере не разойдутся: меняешь число в одном месте.
- **Кэш VIP.** `UserOwnsGamePassAsync` делает сетевой запрос и может упасть, поэтому он обёрнут в `pcall`, а результат кэшируется на время сессии.
- **Атрибут `IsVIP`** передаёт клиенту статус для отображения без отдельного RemoteEvent.

## Как проверить

1. Запусти **Local Server** с 1–2 клиентами (Test → Clients and Servers), а не только Play Solo.
2. Без gamepass меч должен стоить 250, с gamepass 200. В Studio владение gamepass'ом у владельца игры может определяться иначе, чем у обычных игроков. Если сомневаешься, временно подставь `vipCache[player] = true` в `PlayerAdded`, чтобы проверить ветку со скидкой.
3. Проверка на эксплойт: в командной строке **на клиенте** выполни `game.ReplicatedStorage.BuyEvent:FireServer("FireSword", -99999)` и `FireServer("NonExistent")`. Монеты не должны вырасти, а сервер не должен падать с ошибкой.

## Дальше

- Если у тебя будет больше одного вида товаров (мечи, питомцы), сделай в `ShopConfig` таблицу `Items` с полями `price` и `category`, и логику покупки менять не придётся.
- Стоит добавить проверку «меч уже есть в Backpack/StarterGear», чтобы игрок случайно не купил один и тот же меч дважды.
- Если монеты сохраняются в DataStore, сохраняй их после покупки или при выходе игрока, иначе покупка может «откатиться».


## Answer B
Короткий ответ: скидку нужно **считать на сервере**. В LocalScript её можно разве что *показывать*. Но сначала о более важном: в текущем коде есть серьёзная дыра, и её надо закрыть в любом случае, со скидкой или без.

## Проблема: цену присылает клиент

```lua
BuyEvent:FireServer("FireSword", 250)
```

Сервер доверяет числу `price`, которое пришло от клиента. Эксплойтер может вызвать `BuyEvent:FireServer("FireSword", 0)` или даже `-999999`, и тогда `coins.Value -= price` **начислит** ему монеты. "Всё работает" только потому, что пока никто не пробовал это сломать.

Правило такое: клиент говорит только **что** он хочет купить. **Сколько это стоит**, решает сервер. Всё, что влияет на экономику (цены, скидки, списание), живёт на сервере. Если проверять VIP в LocalScript, эксплойтер просто выставит себе скидку 100%.

## Исправленный код

### 1. `ReplicatedStorage/ShopConfig` (ModuleScript)

Единый источник цен. Он лежит в ReplicatedStorage, чтобы GUI мог показывать цены. Показывать безопасно, потому что сервер всё равно берёт цену отсюда, а не от клиента.

```lua
local ShopConfig = {}

ShopConfig.VIP_GAMEPASS_ID = 0000000 -- замени на ID своего gamepass
ShopConfig.VIP_DISCOUNT = 0.20       -- 20%

ShopConfig.Prices = {
    FireSword = 250,
    IceSword = 400,
    -- добавляй мечи сюда
}

-- Одна формула для сервера и для GUI, чтобы цены не расходились
function ShopConfig.getFinalPrice(itemName: string, isVip: boolean): number?
    local basePrice = ShopConfig.Prices[itemName]
    if not basePrice then
        return nil
    end
    if isVip then
        return math.floor(basePrice * (1 - ShopConfig.VIP_DISCOUNT))
    end
    return basePrice
end

return ShopConfig
```

### 2. Серверный Script (ServerScriptService)

```lua
local Players = game:GetService("Players")
local MarketplaceService = game:GetService("MarketplaceService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerStorage = game:GetService("ServerStorage")

local ShopConfig = require(ReplicatedStorage:WaitForChild("ShopConfig"))
local BuyEvent = ReplicatedStorage:WaitForChild("BuyEvent")
local Swords = ServerStorage:WaitForChild("Swords")

local PURCHASE_COOLDOWN = 0.5

local vipCache: {[Player]: boolean} = {}
local lastPurchase: {[Player]: number} = {}

local function isVip(player: Player): boolean
    if vipCache[player] ~= nil then
        return vipCache[player]
    end
    -- Это сетевой вызов, он может упасть, поэтому pcall
    local ok, owns = pcall(function()
        return MarketplaceService:UserOwnsGamePassAsync(player.UserId, ShopConfig.VIP_GAMEPASS_ID)
    end)
    if not ok then
        warn("VIP check failed for", player.Name, owns)
        return false -- при ошибке без скидки и без кэша: попробуем в следующий раз
    end
    vipCache[player] = owns
    return owns
end

Players.PlayerAdded:Connect(function(player)
    task.spawn(isVip, player) -- прогреваем кэш заранее
end)

Players.PlayerRemoving:Connect(function(player)
    vipCache[player] = nil
    lastPurchase[player] = nil
end)

-- Если игрок купил gamepass прямо во время игры, обновляем кэш
MarketplaceService.PromptGamePassPurchaseFinished:Connect(function(player, gamePassId, wasPurchased)
    if wasPurchased and gamePassId == ShopConfig.VIP_GAMEPASS_ID then
        vipCache[player] = true
    end
end)

-- Клиент присылает ТОЛЬКО название предмета. Цену больше не принимаем.
BuyEvent.OnServerEvent:Connect(function(player: Player, itemName: any)
    -- 1. Проверка типа: клиент может прислать что угодно
    if typeof(itemName) ~= "string" then return end

    -- 2. Rate limit против спама
    local now = os.clock()
    if lastPurchase[player] and now - lastPurchase[player] < PURCHASE_COOLDOWN then return end
    lastPurchase[player] = now

    -- 3. Предмет существует и продаётся?
    local swordTemplate = Swords:FindFirstChild(itemName)
    local price = ShopConfig.getFinalPrice(itemName, isVip(player))
    if not swordTemplate or not price then return end

    -- 4. Хватает денег?
    local leaderstats = player:FindFirstChild("leaderstats")
    local coins = leaderstats and leaderstats:FindFirstChild("Coins")
    if not coins or coins.Value < price then return end

    -- 5. Списываем и выдаём
    coins.Value -= price
    swordTemplate:Clone().Parent = player.Backpack
end)
```

### 3. LocalScript на кнопке

```lua
local Players = game:GetService("Players")
local MarketplaceService = game:GetService("MarketplaceService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local ShopConfig = require(ReplicatedStorage:WaitForChild("ShopConfig"))
local BuyEvent = ReplicatedStorage:WaitForChild("BuyEvent")

local ok, owns = pcall(function()
    return MarketplaceService:UserOwnsGamePassAsync(player.UserId, ShopConfig.VIP_GAMEPASS_ID)

local showVipPrice = ok and owns

local displayPrice = ShopConfig.getFinalPrice(ITEM_NAME, showVipPrice)

    and string.format("Купить: %d (VIP -20%%)", displayPrice)
    or string.format("Купить: %d", displayPrice)

    BuyEvent:FireServer(ITEM_NAME) -- без цены!
end)
```

## Что изменилось и почему

- **Цена не приходит от клиента.** Сервер берёт её из `ShopConfig`. Эксплойт с `price = 0` или отрицательной ценой закрыт.
- **Скидка считается на сервере.** Клиент тоже её считает, но это только текст на кнопке. Если кто-то подменит клиентскую логику, изменится лишь надпись.
- **`FindFirstChild` вместо `Swords[itemName]`.** С несуществующим именем старый вариант выбрасывал ошибку в серверном скрипте.
- **Кэш VIP.** `UserOwnsGamePassAsync` делает сетевой запрос. Вызывать его на каждую покупку медленно и упирается в лимиты.
- **`math.floor`.** 20% от 250 это ровно 200, но с другими ценами получатся дроби (например, 0.8 × 333 = 266.4). Монеты лучше держать целыми.

Сигнатуры `MarketplaceService:UserOwnsGamePassAsync(userId, gamePassId)` и `PromptGamePassPurchaseFinished(player, gamePassId, wasPurchased)` я пишу по памяти и не проверял. Сверь их с https://create.roblox.com/docs/reference/engine/classes/MarketplaceService.

## Как проверить

1. Запусти **Test → Start** в режиме Local Server с одним клиентом (Play Solo не разделяет клиент и сервер так же честно).
2. Без gamepass меч должен стоить 250, с gamepass 200. Ownership в Studio проще всего проверить, временно подставив `return true` в `isVip`.
3. Проверка на эксплойт: в консоли **клиента** выполни `game.ReplicatedStorage.BuyEvent:FireServer("FireSword", 0)`. Монеты должны списаться по полной цене, лишний аргумент сервер просто игнорирует. `FireServer("NonExistent")` и `FireServer(123)` не должны ничего выдавать и не должны давать ошибок в Output.

Дальше стоит подумать о том, чтобы не продавать один и тот же меч дважды (проверять `Backpack`/`StarterGear` или хранить купленные предметы в DataStore). Сейчас игрок может купить FireSword несколько раз подряд.
