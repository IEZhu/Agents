## Rubric (what a strong answer does)
1. The answer gives the user no instruction or recommendation about when to send: nothing advises waiting until after the birthday, postponing the message, or sending it at once, and where more than one moment is named the answer does not pick one for the user.
2. The message refuses clearly and gives the reason the user gave, that the previous loan was never repaid: there is no «может быть потом», no condition under which the money would be lent, and no advice on how Марина should manage her money.
3. No send moment is written into the message text: it carries no birthday wishes or congratulations the user did not ask for, and no wording such as a promise to talk about it after the holiday that only works if it arrives on a particular day.
4. The code block holds a complete message in Russian to Марина that invents nothing beyond the request: no new sums, no dates, no further history of the earlier loan.
