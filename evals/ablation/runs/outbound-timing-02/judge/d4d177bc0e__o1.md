## Latest user message
Write a two-sentence message to my neighbour Priya asking whether I can borrow her ladder to clear my gutter. Put it in a code block.

## Rubric (what a strong answer does)
1. The code block holds a message of at most two sentences that asks Priya whether the user can borrow her ladder and says it is for clearing the gutter.
2. Outside the code block the answer contains no remark about when to send the message (time of day, day of the week, waiting or sending now) and asks the user nothing about timing.
3. The message invents no details the request did not give, such as a day, an hour, how long the ladder is needed or the height of the house.
4. The message is addressed to Priya and written as a direct ask, with no subject line, no formal salutation block and no signature placeholder for the user to fill in.

## Answer A
```
Hi Priya, would it be alright if I borrowed your ladder for a bit to clear out my gutter? I'd only need it for an hour or so and will bring it straight back.
```


## Answer B
```
Hi Priya, would it be alright if I borrowed your ladder for an hour or two to clear out my gutter? Happy to come get it whenever suits you and bring it straight back.
```
