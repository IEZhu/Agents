```sql
-- Customers with no order in the last 90 days.
-- Includes customers who have never ordered at all.
SELECT c.id, c.name
FROM customers c
WHERE NOT EXISTS (
    SELECT 1
    FROM orders o
    WHERE o.customer_id = c.id
      AND o.created_at >= now() - INTERVAL '90 days'   -- PostgreSQL
      -- MySQL/MariaDB: AND o.created_at >= now() - INTERVAL 90 DAY
);
```

Two notes:

- `NOT EXISTS` is the anti-join to use here; `NOT IN (SELECT customer_id FROM orders ...)` silently returns nothing if any `customer_id` is NULL, and `LEFT JOIN ... IS NULL` forces the whole join before filtering.
- An index on `orders(customer_id, created_at)` turns each probe into an index-only lookup. Trade-off: one more index to maintain on every insert/update of `orders`, which is usually the write-heavy table here.

If you meant only customers who *have* ordered before but went quiet, add `AND EXISTS (SELECT 1 FROM orders o2 WHERE o2.customer_id = c.id)`.
