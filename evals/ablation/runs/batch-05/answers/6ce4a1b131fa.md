В моём прошлом ответе была ошибка, и в смету её переносить нельзя. Я перевёл расход неверно: поделил на 60, хотя в часе 3600 секунд. Из-за этого мощность вышла завышенной в 60 раз.

## 1. Гидравлическая мощность (исправлено)

Q = 18 м³/ч ÷ 3600 с/ч = 0,005 м³/с

P_гидр = ρ·g·Q·H = 1000 кг/м³ · 9,81 м/с² · 0,005 м³/с · 32 м = **1570 Вт ≈ 1,57 кВт**

Проверка на здравый смысл: 94 кВт при 18 м³/ч — это уровень магистрального насоса, для контура охлаждения станка такое невозможно. 1,5–3 кВт для этого класса выглядит правдоподобно.

## 2. Мощность на валу и выбор двигателя

Мощность на валу насоса:
P_вал = P_гидр / η_н = 1,570 / 0,65 = **2,41 кВт**

С запасом 15%:
P_дв = 2,41 · 1,15 = **2,78 кВт**

Стандартный ряд IEC вокруг этого значения: 2,2 → **3,0** → 4,0 кВт. Двигатель на 2,2 кВт слишком слабый, поэтому **берём 3,0 кВт**. Реальный запас получится 3,0 / 2,41 ≈ 1,24, то есть около 24%.

Частоту вращения (обычно 3000 об/мин для такого напора) и исполнение нужно брать из паспорта конкретного насоса. Производитель часто сам комплектует насос двигателем, и тогда выбирать ничего не нужно.

## 3. Электроэнергия за год

Запас мощности электричество не расходует. Двигатель потребляет столько, сколько реально требует вал (2,41 кВт), плюс собственные потери. КПД двигателя 3 кВт класса IE3 я беру ≈ 0,87 (значение по памяти, не проверено здесь; точное смотрите в паспорте двигателя).

P_эл = 2,41 / 0,87 ≈ 2,78 кВт
W = 2,78 кВт · 6000 ч ≈ **16 700 кВт·ч/год**
Стоимость = 16 700 · 7,2 руб/кВт·ч ≈ **120 000 руб/год**

Проверка размерности: кВт · ч = кВт·ч, а кВт·ч · руб/(кВт·ч) = руб. Всё сходится.

Для ориентира:
- без учёта КПД двигателя (нижняя граница): 2,41 · 6000 · 7,2 ≈ 104 000 руб;
- если грубо считать по номиналу 3 кВт / 0,87: ≈ 149 000 руб. Это завышенная оценка, ведь двигатель недогружен.

## Для сметы

| Параметр | Значение |
|---|---|
| Гидравлическая мощность | 1,57 кВт |
| Мощность на валу (η = 0,65) | 2,41 кВт |
| Требуемая с запасом 15% | 2,78 кВт |
| **Двигатель** | **3,0 кВт** |
| Потребляемая мощность | ≈ 2,8 кВт |
| Энергия за год (6000 ч) | ≈ 16 700 кВт·ч |
| **Стоимость электроэнергии** | **≈ 120 тыс. руб/год** |

Оговорка: расчёт верен, если насос реально работает в точке 18 м³/ч и 32 м. Если фактическое сопротивление контура меньше, рабочая точка сместится вправо по характеристике насоса, и потребление изменится. Поэтому рабочую точку стоит сверить с кривой насоса из каталога.
