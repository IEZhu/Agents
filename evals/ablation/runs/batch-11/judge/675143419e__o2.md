## Answer A
**Коротко:** одним промптом формат на 100% не удержать, даже капсом. Надёжная схема держится на двух вещах: (1) промпт с жёстким контрактом, примером и prefill, (2) валидатор в скрипте с retry. Ещё надёжнее просить у модели JSON и собирать markdown самому в коде. Тогда `##` против `###`, обёртки ```` ``` ```` и лишние разделы исключены конструктивно.

## Почему текущий промпт «плывёт»

- Инструкция, шаблон и данные лежат одной кашей в user-сообщении. Модель не видит, где кончается шаблон и начинается вход.
- Нет ни одного примера готового выхода. «Строго соблюдай формат» — абстракция, а пример — конкретика.
- Не сказано, **что делать с пустыми/неизвестными полями**. Отсюда модель добавляет «Возможные причины» и сама придумывает ссылки на Grafana.
- Ответ модель начинает с нуля, поэтому «Конечно! Вот…» — самый вероятный первый токен.
- Капс работает слабо: он говорит, чего *не* делать, но не показывает, что делать.

```python
import json

REQUIRED = {"alert_name", "severity", "what_broke", "first_action", "diagnostics", "grafana"}

def render(d: dict) -> str:
    diag = "\n".join(f"- `{c.strip('`')}`" for c in d["diagnostics"])
    return (
        f"## {d['alert_name']}\n"
        f"**Severity:** {d['severity']}\n"
        f"**Что сломалось:** {d['what_broke']}\n"
        f"**Первое действие:** {d['first_action']}\n"
        f"**Диагностика:**\n{diag}\n"
        f"**Grafana:** {d['grafana']}\n"
    )

def parse(raw: str) -> dict:
    raw = raw.strip().removeprefix("```json").removeprefix("```").removesuffix("```").strip()
    d = json.loads(raw)
    if set(d) != REQUIRED or d["severity"] not in {"critical", "warning", "info"}:
        raise ValueError(f"bad keys/severity: {sorted(d)}")
    return d
```

## Страховка в скрипте (обязательна для обоих вариантов)

```python
import re

CARD_RE = re.compile(
    r"\A## \S+\n"
    r"\*\*Severity:\*\* (critical|warning|info)\n"
    r"\*\*Что сломалось:\*\* .+\n"
    r"\*\*Первое действие:\*\* .+\n"
    r"\*\*Диагностика:\*\*\n"
    r"(- `kubectl [^\n]+`\n)+"
    r"\*\*Grafana:\*\* \S.*\Z"
)

def clean(text: str) -> str:
    text = text.strip()
    text = re.sub(r"\A```\w*\n|\n```\Z", "", text)   # снять обёртку
    start = text.find("## ")
    return text[start:].strip() if start != -1 else text

def generate(rule_yaml, alert_name, retries=2):
    for attempt in range(retries + 1):
        out = clean(call_llm(rule_yaml, alert_name))   # ваш вызов
        if CARD_RE.match(out):
            return out
        # в retry добавьте в user-сообщение: "Предыдущий ответ не прошёл валидацию: <что не так>. Выведи только карточку."
    raise ValueError(f"{alert_name}: format failed after {retries + 1} attempts")
```

Плюс `temperature=0`: на 140 однотипных вызовах это заметно снижает разброс.

## Что это даст

- Вариант A + JSON schema mode: сбоев формата практически нет, остаются только проблемы содержания.
- Вариант B + prefill + валидатор + retry: оценочно (не мерил) должен остаться примерно 1% ручных разборов, а не 15-20%, и бот больше не падает, потому что невалидное до него не доходит.

Тексты «Что сломалось» и «Первое действие» всё равно стоит один раз просмотреть глазами для critical-алертов. Формат валидатор проверит, а правильность команды — нет.

| Симптом | Причина | Лечение |
|:---|:---|:---|
| «Конечно! Вот карточка…» | Режим чат-ассистента, ответ ничем не заякорен | Prefill `## ` или JSON-режим |

import re

CARD_RE = re.compile(
    r"\A## \S+\n"
    r"\*\*Severity:\*\* (critical|warning|info)\n"
    r"\*\*Что сломалось:\*\* .+\n"
    r"\*\*Первое действие:\*\* .+\n"
    r"\*\*Диагностика:\*\*\n(- `kubectl [^\n]+`\n){1,6}"
    r"\*\*Grafana:\*\* \S.*\Z"
)

def clean(text: str) -> str:
    text = text.strip()
    text = re.sub(r"\A```\w*\n|\n```\Z", "", text).strip()  # снять обёртку
    i = text.find("## ")                                      # отрезать вступление
    text = text[i:] if i >= 0 else text
    text = re.sub(r"\A#{3,} ", "## ", text)                   # ### -> ##
    m = re.search(r"^\*\*Grafana:\*\*.*$", text, re.M)        # отрезать хвост после Grafana
    return text[: m.end()] if m else text

def get_card(rule_yaml, grafana_url, retries=2):
    for _ in range(retries + 1):
        card = clean(call_llm(rule_yaml, grafana_url))  # temperature=0
        if CARD_RE.match(card):
            return card
    raise ValueError("card format failed")  # в лог, на ручную проверку
```

## Что ещё сделать

- **`temperature=0`**: для 140 однотипных генераций креативность не нужна.
- **Убрать капс.** С примером и prefill он лишний, а явное «НЕ …» иногда даже провоцирует нарушение.
- **`severity` брать из YAML в коде**, а не просить модель: это детерминированное поле.
- **Логировать провалы валидации.** Если после всех правок останется 1-2%, это решает retry, а не дальнейшая шлифовка промпта.

По опыту, вариант A с schema-режимом API снимает проблему практически полностью. Вариант B с prefill, примером и `clean()` плюс retry, скорее всего, тоже доведёт брак до единичных случаев, но гарантий меньше.
